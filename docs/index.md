# 人工智能与地理数据挖掘

**作者**：孙伟 · 中山大学地理科学与规划学院
**最后更新**：2026-10-27

欢迎访问《人工智能与地理数据挖掘》课程在线书稿。本书以机器学习方法为主线，结合地学应用场景，系统讲解从数据预处理、可视化到聚类、降维、分类与回归建模的完整流程。

> **全书总纲**：同一张"类别—功能"二维表格，"横着切"得到聚类，"竖着切"得到降维，"看着 Y 竖着切"得到特征选取，"由 X 预测 Y"得到分类与回归——四大功能由此而来。

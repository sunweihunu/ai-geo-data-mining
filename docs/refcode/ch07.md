此示例显示如何按以下方式对查询数据进行分类： 产生 Kd 树，进行 k 最近邻搜索。 为每个查询点分配其各自最近邻居中具有最高表示的类。

??? example "展开代码"

    ```matlab
    % 分类查询数据
    % 此示例显示如何按以下方式对查询数据进行分类：
    % 产生 Kd 树，进行 k 最近邻搜索。
    % 为每个查询点分配其各自最近邻居中具有最高表示的类。
    clear
    %% Step 1:  根据 Fisher iris 数据的最后两列对新点进行分类。仅使用最后两列可以更轻松地绘制。
    load fisheriris
    x = meas(:,3:4);
    figure;
    gscatter(x(:,1),x(:,2),species)
    legend('Location','best')
    
    
    %%  Step 2:  准备一个 Kd 树最近邻搜索器模型。
    Mdl = KDTreeSearcher(x)
    % Mdl 是一个 KDTreeSearcher 模型。
    % 默认情况下，它用于搜索邻居的距离度量是欧几里得距离。
    
    
    %%  Step 3:  对一个新点进行分类
    % 绘制新点。新点的两个坐标是5和 1.45
    newpoint = [5 1.45];
    line(newpoint(1),newpoint(2),'marker','x','color','k',...
        'markersize',10,'linewidth',2)
    
    % 找到最接近新点的 10 个样本点。
    [n,d] = knnsearch(Mdl,newpoint,'k',10);
    line(x(n,1),x(n,2),'color',[.5 .5 .5],'marker','o',...
        'linestyle','none','markersize',10)
    
    % knnsearch 似乎只找到了最近的八个邻居。事实上，这个特定的数据集包含重复的值。
    x(n,:)
    
    % 重新画图，使轴相等，以便计算出的距离与绘图轴上的表观距离相等，然后放大以更好地查看邻居。
    figure;
    gscatter(x(:,1),x(:,2),species)  % 重新画图
    line(newpoint(1),newpoint(2),'marker','x','color','k',...
        'markersize',10,'linewidth',2)
    xlim([4.5 5.5]);
    ylim([1 2]);
    axis square
    
    % 显示点坐标
    fprintf('\n%s\n','1个数据点坐标如下');
    disp(newpoint);
    % 找出 10 个邻居的类别。
    fprintf('\n%s\n','kNN计算的该点的占每类比例')
    tabulate(species(n))
    % 使用基于 10 个最近邻点的多数票的规则，您可以将此新点归类为杂色点。
    
    
    % 通过在邻居组周围画一个圆圈来直观地识别邻居。根据新点的位置定义圆的中心和直径。
    ctr = newpoint - d(end);
    diameter = 2*d(end);
    % 在 10 个最近的邻居周围画一个圆圈。
    h = rectangle('position',[ctr,diameter,diameter],...
        'curvature',[1 1]);
    h.LineStyle = ':';
    
    %%  Step 4:  对三个新点进行分类
    % 使用相同的数据集，找到三个新点的 10 个最近邻。
    figure
    newpoint2 = [5 1.45;6 2;2.75 .75];
    gscatter(x(:,1),x(:,2),species)
    legend('location','best')
    [n2,d2] = knnsearch(Mdl,newpoint2,'k',10);
    line(x(n2,1),x(n2,2),'color',[.5 .5 .5],'marker','o',...
        'linestyle','none','markersize',10)
    line(newpoint2(:,1),newpoint2(:,2),'marker','x','color','k',...
        'markersize',10,'linewidth',2,'linestyle','none')
    
    % 显示点坐标
    fprintf('\n%s\n','三个数据点坐标如下')
    disp(newpoint2);
    % 为每个新点找出 10 个最近邻的类别。
    fprintf('\n%s\n','kNN计算的每个点的占每类比例')
    tabulate(species(n2(1,:)))
    tabulate(species(n2(2,:)))
    tabulate(species(n2(3,:)))
    
    % 给出具体的分类
    cc={};
    for nn=1:3
        c1=tabulate(species(n2(nn,:)));
        [a,b]=max(cell2mat(c1(:,2)));  % 投票法找到最大个数对应的类别
        cc=[cc; c1(b,1)]; % 存到cc
    end
    fprintf('\n%s\n','kNN计算的每个点的最后类别')
    disp(cc)
    ```

??? example "展开代码"

    ```matlab
    % 使用 createns 函数生成 Kd 树最近邻搜索器对象。
    % 将对象和查询数据传递给 knnsearch 函数以查找 k 最近邻。
    
    %%  Step 1 ===> 加载Fisher's 鸢尾花数据集.
    load fisheriris
    
    %%  Step 2 ===> 从预测器数据中随机删除五个鸢尾花以用作查询集。 
     
    rng(1);                     % 固定随机种子
    n = size(meas,1);           % meas总数据集的样本个数
    qIdx = randsample(n,5);     % 查询数据集的序号
    tIdx = ~ismember(1:n,qIdx); % 去掉查询数据集的序号，生成训练数据集的序号
    Q = meas(qIdx,:);           % 根据查询数据集的序号，获得查询数据集
    X = meas(tIdx,:);           % 根据训练数据集的序号，获得训练数据集
    
    %%  Step 3 ===>  使用训练数据生成四维 Kd 树。 指定用于查找最近邻的 Minkowski 距离。
    Mdl = createns(X,'Distance','minkowski')
    % 因为 X 有四列，距离度量是 Minkowski，createns 默认创建一个 KDTreeSearcher 模型对象。
    % Minkowski 距离指数默认为 2。
    
    
    %%  Step 4 ===>  查找作为查询数据 (Q) 中每个点的两个最近邻居的训练数据 (Mdl.X) 的索引。
    IdxNN = knnsearch(Mdl,Q,'K',2)
    % IdxNN 的每一行对应一个查询数据观察，列顺序对应最近邻的顺序，相对于升序。 
    % % 例如，根据闵可夫斯基距离，Q(3,:)的第二近邻是X(12,:)。
    ```

kNN模型的构建，采用了ExhaustiveSearcher或createns 最近邻的搜索采用了knnsearch 并且观察了k对kNN分类效果的影响

??? example "展开代码"

    ```matlab
    % 本例子采用四个自变量，把所有数据集作为训练集，进行kNN分类
    % kNN模型的构建，采用了ExhaustiveSearcher或createns
    % 最近邻的搜索采用了knnsearch
    % 并且观察了k对kNN分类效果的影响
    
    %% Step 1  ===>  加载 Fisher 的鸢尾花数据集。
    clear all;
    load fisheriris
    X = meas;
    [n,k] = size(X)
    % X 有 150 个观测值和 4 个自变量。
    
    %% Step 2A  ===>  使用整个数据集作为训练数据准备一个详尽的最近邻搜索器。
    Mdl1 = ExhaustiveSearcher(X)
    % Mdl1 是 ExhaustiveSearcher 模型对象，其属性显示在命令行窗口中。
    % 该对象包含有关经过训练的算法的信息，例如距离度量。 您可以使用点表示法更改属性值。
    
    %% Step 2B  ===>  和 Step 2A 等价，实际问题中二者取一个即可
    % 或者，您可以通过使用 createns 并指定 'exhaustive' 作为搜索方法来准备一个详尽的最近邻搜索器。
    Mdl2 = createns(X,'NSMethod','exhaustive')
    % Mdl2 也是一个 ExhaustiveSearcher 模型对象，它等价于 Mdl1。
    % 要为一批查询数据搜索 X 的最近邻居，请将 ExhaustiveSearcher 模型对象和查询数据传递给 knnsearch 或 rangesearch。
    
    %%  Step 3 ===>  使用Mdl1,对所有X来查询他们在X中的最近邻居
    IdxNN1 = knnsearch(Mdl1,X,'K',2);
    IdxNN2 = knnsearch(Mdl2,X,'K',2);
    [IdxNN1 IdxNN2] % 因为 Mdl2 等价于 Mdl1，IdxNN1和IdxNN2完全相同
    
    %%  Step 4 ===>  观察k对分类效果的影响
    % 使用四个自变量来分类，不好直接四维画图，而用1维的个数，颜色区分类别进行画图，
    % 纵轴显示k的个数
    figure;hold on;
    gscatter(1:n,ones(n),species)  % 所有类别按1到150画图
    for kk=2:5
        IdxNN_kk = knnsearch(Mdl1,X,'K',kk);
        % 给出具体的分类, 存到cc
        cc={};
        for ii=1:n  % n=150个样本
            c1=tabulate(species(IdxNN_kk(ii,:)));
            [a,b]=max(cell2mat(c1(:,2)));  % 投票法找到最大个数对应的类别
            cc=[cc; c1(b,1)]; % 存到cc
        end
        gscatter(1:n,kk*ones(n),cc)
    end
    xlabel('样本数');
    ylabel('k');
    ```

    ```matlab
    % 完全按照定义自己写代码
    % 仅供参考，需要进一步仔细检查代码
    
    clc
    clear all
    close all
    warning off
    % 1. 导入训练数据：5位同学各自得两门学科（数学和电子）得成绩以及对应结果（过关和没过关）
    x=[4 6 7 5 8];
    y=[3 7 8 5 8];
    c=["Fail","Pass","Pass","Fail","Pass"];
    
    % 2. 选定k值
    k=3;
    
    % 3. 输入测试样本：新来的一位同学两门学科的成绩
    a=6;b=8;
    
    % 4. 计算和训练数据之间的距离，并排序
    distance=[];
    for i=1:length(x)
        e=sqrt((x(i)-a)^2+(y(i)-b)^2);
        distance=[distance e];
    end
    
    % 距离排序
    temp=0;
    gemp=0;
    for i=1:length(distance)
        for j=1:(length(distance)-i)
            if(distance(j)>distance(j+1))
                temp=distance(j);
                distance(j)=distance(j+1);
                distance(j+1)=temp;
                gemp=c(j);
                c(j)=c(j+1);
                c(j+1)=gemp;
            end
        end
    end
    % 5. 选取距离最近的k个训练数据的结果中出现频率最高的结果作为最后预测的结果
    classy=[];
    for i=1:k
        classy=[classy c(i)];
    end
    output=string(mode(categorical(classy)))
    ```

    ```matlab
    % Find Nearest Points in Clustered Data using rangesearch
    % https://ww2.mathworks.cn/help/stats/rangesearch.html
    %% Generate 5000 random points from each of three distinct multivariate normal distributions. 
    % Shift the means of the distributions so that the randomly generated points 
    % are likely to form three separate clusters.
    rng('default')  % For reproducibility
    N = 5;
    dist = 10;
    %  mvnrnd - Multivariate normal random numbers
    %     This MATLAB function returns a matrix R of n random vectors chosen from
    %     the same multivariate normal distribution, with mean vector mu and
    %     covariance matrix Sigma.
    %     R = mvnrnd(mu,Sigma,n)
    %     R = mvnrnd(mu,Sigma)
    X = [mvnrnd([0 0],eye(2),N);
         mvnrnd(dist*[1 1],eye(2),N);
         mvnrnd(dist*[-1 -1],eye(2),N)];
    %% For each point in X, find the points in X that are within a radius dist away from the point. 
    % For faster computation, specify to keep the indices of the nearest neighbors unsorted. 
    % Select the first point in X, and find its nearest neighbors.
    Idx = rangesearch(X,X,dist,'SortIndices',false);
    x = X(1,:);
    nearestPoints = X(Idx{1},:);
    %% Find the values in X that are not the nearest neighbors of x.
    nonNearestIdx = true(size(X,1),1);
    nonNearestIdx(Idx{1}) = false;
    
    % Display those points in one color and the nearest neighbors of x in a different color. 
    scatter(X(nonNearestIdx,1),X(nonNearestIdx,2))
    hold on
    scatter(nearestPoints(:,1),nearestPoints(:,2))
    
    scatter(x(1),x(2),'black','filled')  % Label the point x with a black, filled circle.
    hold off
    ```

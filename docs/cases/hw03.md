# 附录C 地貌案例：滑坡敏感性制图（LSM）

> **案例导读**：一场强降雨过后，一条山谷里哪里最容易发生滑坡？滑坡敏感性映射（Landslide Susceptibility Mapping, LSM）用"历史滑坡点 + 环境调节因子"训练分类模型，为全区域每个格点算出滑坡概率，再按概率分级成图，是地质灾害风险分区的基础。本案例以四川冕宁县安宁河流域为研究区，从 DEM 派生地形因子、叠加岩性/降雨/植被等多源数据，经 VIF 与信息增益筛选因子后，用决策树/随机森林/SVM/kNN 四种模型训练对比，把最优模型的概率输出分成 5 级易发性分区图。本案例的方法流程与[第23章 土地篇](../ch23.md)的"六步建模"完全对应——先把书上的流程读懂，再动手实现一遍。

**对应要素**：地貌　|　**难度**：★★　|　**建议学时**：8~12 学时（2~3 人一组）
**方法对应**：[第04章 聚类分析](../ch04.md) · [第07章 k最近邻](../ch07.md) · [第08章 决策树](../ch08.md) · [第23章 地学应用三：土地篇](../ch23.md)

## C.1 案例背景与研究问题

### C.1.1 地学背景

滑坡敏感性映射旨在评估给定区域发生滑坡的**可能性**，是地质灾害风险分区的基础。其影响因素（滑坡调节因子，LCF）包括地形（坡度、坡向、曲率）、水文（降雨、地形湿度指数 TWI）、地质（岩性、断层距离）、土地覆被等。机器学习方法（决策树、随机森林、SVM、kNN）已是 LSM 的主流工具。LSM 回答的是"哪里**容易**发生"（敏感性），与"什么时候发生"（危险性）和"损失多大"（风险）共同构成完整的灾害评估链条。

**滑坡的力学本质：一场"下滑力 vs 抗剪强度"的对抗。** 斜坡稳定取决于两支力量的平衡：**下滑力**——自重沿坡面的切向分量，随坡角增大；**抗剪强度**——滑面抵抗剪切破坏的能力，常用莫尔–库仑准则描述：

$$\tau_f = c' + (\sigma - u)\tan\varphi'$$

其中 $c'$ 是内聚力，$\sigma$ 是法向应力，$u$ 是**孔隙水压力**（裂隙与孔隙中水的压强），$\varphi'$ 是内摩擦角。当下滑力逼近甚至超过 $\tau_f$，斜坡失稳。理解了这个对抗，就能明白每类因子"各自站在哪一侧"：

- **坡度**站在下滑力一侧——$\beta$ 增大直接放大自重切向分量，是最直接的一项；
- **岩性、构造（断层）**站在抗剪强度一侧——软弱岩层（泥岩、页岩等）的 $c'$、$\varphi'$ 天然偏低；断层带岩体破碎，既削弱强度又导水；
- **水文（降雨、TWI）**通过 $u$ 起作用——降雨入渗抬高孔隙水压力，$(\sigma-u)$ 被压小、抗剪强度骤降，这正是"雨后滑坡"的力学解释；
- **坡向、植被（NDVI、土地利用）**是间接调制项——经日照风化、蒸发与根系固土缓慢改变 $c'$、$\varphi'$ 与入渗条件。

!!! note "敏感性（susceptibility）与危险性（hazard）不是一回事"
    **敏感性**是空间条件概率：给定环境条件下某像元"倾向于"发生滑坡的程度，回答"**哪里容易滑**"，**不含时间维度**。**危险性**再加入触发事件的时序概率：$P(\text{时间窗 } T \text{ 内发生}) = P(\text{条件易滑}) \times P(\text{触发在 } T \text{ 内超越阈值})$。再乘承灾体**易损性**才是**风险**。本案例只做第一环，故全篇用"敏感性/易发性"，报告用词不要混用。

**为什么降雨是研究区的主要触发因素？** 安宁河流域地处川西南山地，降雨集中于雨季且多短时强降雨——雨水大量入渗，正是 $u$ 骤升、抗剪强度骤降的典型场景，区内历史滑坡、泥石流与暴雨过程高度同步；备选研究区（舟曲"8·8"泥石流，见 C.6.2 提取示例；福建台风区）同理。所以本案例把降雨选入因子集，并在 T7 检查误判点是否与降雨格局有关。

**为什么 LSM 适合机器学习？** 因为"因子 → 滑坡"是**高度非线性的空间模式识别问题**：坡度与滑坡常呈"倒 U 形"（过陡处松散物反而薄）、TWI 有阈值效应、因子交互多（陡坡 × 软岩 × 强降雨才最危险），写不成一条解析公式。而历史编目是"大自然做过的实验"——每个编目点记录了一次"在这组因子取值下真的滑了"。机器学习擅长从样本归纳非线性与交互效应，再把"因子空间 → 滑坡概率"外推到全域像元——正是[第23章](../ch23.md)所说"X 全域已知、Y 局部已知"的空间预测问题。

### C.1.2 研究问题

以某山区为研究区，构建滑坡敏感性概率格网。问题分四层递进：

- **基础问题①（因子构建）**：由 DEM 派生坡度/坡向/TWI，叠加岩性、降雨、NDVI、断层距离等因子；
- **基础问题②（分类建模）**：以滑坡编目为标签（滑坡=1，非滑坡=0），用决策树/随机森林/SVM/kNN 训练二分类模型；
- **基础问题③（特征选择）**：用 VIF、信息增益（IG）筛选因子，避免多重共线；
- **复合问题**：构建"**因子构建 → 特征选择 → 多模型训练 → AUC 对比 → 概率格网制图**"的完整 LSM 工作流，并按概率分 5 类易感性等级。

四层不是并列的四道题，而是同一张成图的四道工序：①"X 从哪来"（因子构建）；②"Y 是什么、用什么模型学"（编目为标签的二分类）；③"X 里留谁去谁"（特征选择）；④串成可复现流水线并交付成图。报告"问题定义"一节建议按这条工序线组织。

### C.1.3 地学假设

1. 滑坡发生是地形、地质、水文、植被等因子共同作用的概率事件；
2. 滑坡点与调节因子之间存在统计可分性——历史编目是"大自然做过的实验"；
3. 不同模型对因子非线性关系的刻画能力不同，多模型对比可提升稳健性。

三条假设对应三类检验：假设 1 靠单因子箱线图与频率比（T3 与 C.7）；假设 2 靠 AUC 是否显著高于 0.5 与单一因子基准；假设 3 靠多模型对比表的排名一致性（T5）。检验不通过时回到假设找原因——是因子池缺信息还是编目质量差——而不是只报一个差指标了事。

## C.2 学习目标

## C.3 数据集

### C.3.1 主数据集（推荐研究区：四川冕宁县安宁河流域）

| 数据 | 来源 | 分辨率 | 字段 |
|------|------|--------|------|
| DEM | SRTM 30m / ASTER GDEM | 30 m | 高程 |
| 岩性/断层 | 中国地质调查局 1:50 万地质图 | 矢量 | 岩性类型、断层线 |
| 滑坡编目 | 国土资源部地质灾害详查 / 文献 | 点矢量 | 坐标、类型、体积、时间 |
| 降雨 | GPM / CHIRPS | 0.05°/日 | 年降雨、最大日降雨 |
| NDVI | MODIS MOD13 | 250 m/16d | 植被指数 |
| 土地覆被 | GlobeLand30 | 30 m | 类型 |

**坐标系**：统一为投影坐标系 CGCS2000 / UTM Zone 48N（按研究区选分带），所有栅格重采样至 30 m。**坐标系不统一是 LSM 作业最致命的错误**——编目点和因子层错位半个像元，模型学到的是噪声。

为什么"必须统一"？六种数据的原生空间参考各不相同（DEM 是经纬度格网、地质图是投影矢量、GPM 是 0.05° 格点、MODIS 有自己的投影与 250 m 分辨率），不统一则"同一像元"在各图层里对应的地面位置不重合——编目点读到的可能是隔壁山头的坡度。更麻烦的是这种错误**在精度指标上不可见**：AUC 照样算得出来，模型学到的却是配准误差而非地学规律。三件事把这一步做扎实：

1. **投影选对分带**：研究区在东经 102° 附近属 UTM 48 带；换研究区分带跟经度走（三峡 110°E 用 49 带、福建 118°E 用 50 带）；
2. **重采样按数据类型选**：连续量（高程、降雨、NDVI）用双线性或三次卷积；**类别量（岩性、土地覆被）只能用最近邻**——对类别插值会算出"岩性 2.5"这种无意义值；
3. **逐图层抽查配准**：挑 2~3 个多图层都可辨认的地物（坝址、道路交叉口、河流汇口），核对像元位置是否一致。

**数据获取**：SRTM https://earthexplorer.usgs.gov ；GPM https://gpm.nasa.gov/data ；GlobeLand30 http://www.globallandcover.com ；滑坡编目可用 USGS Landslide Inventory 或文献公开数据替代。

### C.3.2 因子派生要点

- **坡度/坡向/曲率**：由 DEM 用 `gradient`/`surfnorm` 派生；
- **TWI（地形湿度指数）**：$\ln(A_s/\tan\beta)$，$A_s$ 为汇流累积量、$\beta$ 为坡度；
- **距断层距离**：对断层线做欧氏距离变换；
- **降雨侵蚀力 R**：由年降雨经验公式估算。

派生只是"算出来"，选进模型之前你还要能回答"它为什么有用"。对照 C.1.1 的力学平衡，每个因子都各占一环：

| 因子 | 为什么重要（对斜坡平衡的意义） | 取值与派生注意 |
|------|------------------------------|----------------|
| 坡度 | 下滑力的直接项：自重沿坡分量随坡角增大（见 C.1.1） | 与滑坡常呈"倒 U 形"，别预设单调关系 |
| 坡向 | 日照时长差异 → 风化速率与植被差异；迎风坡降雨多、背风坡少 | **角度是环形量**，0°与 359°其实相邻；建议拆成 $\sin$/$\cos$ 两列或按 8 方向归类，否则模型会把"北坡"与"近北坡"当成天壤之别 |
| 平面曲率 | 沿等高线方向的凹凸：凹形聚流、凸形散流，改变局部汇水量 | 派生前先平滑去噪（见 T3） |
| 剖面曲率 | 沿最大坡降方向的凹凸：决定坡面流加速/减速，影响侵蚀与堆积 | 曲率对 DEM 噪声极敏感 |
| TWI | 综合汇流面积 $A_s$ 与坡度 $\beta$ 的地形湿度代理：汇水多且坡缓处土壤易饱和、孔隙水压力高 | 是"降雨响应倾向"的静态代理，不含真实降雨 |
| 距断层距离 | 断层带岩体破碎 → 强度低且导水，近断层更易滑 | 欧氏距离变换输出"每像元到最近断层线的距离" |
| 距水系距离 | 河流侧蚀掏刷坡脚（坡脚侵蚀），并控制地下水位基面 | 近河谷处取值小 |
| 距道路距离 | 人工开挖切坡、爆破与堆载是典型的人为诱发项 | 反映人类活动强度 |
| 岩性 | 直接决定 $c'$ 与 $\varphi'$：软岩易滑、硬岩稳 | 类别变量：独热编码或按易滑程度分级赋值 |
| 土地利用 | 耕地/裸地固土差、建设用地常伴随切坡、林地根系固土 | 类别变量，处理同岩性 |
| NDVI | 植被覆盖度：根系固土、蒸腾排水、削弱雨滴溅蚀 | 0~1 连续量；注意物候期，选少云时段合成 |
| 降雨侵蚀力 R | 触发侧因子：雨量 × 雨强决定入渗与孔隙水压力响应 | 0.05° 格点先重采样到 30 m 再参与堆叠 |

!!! warning "非滑坡样本怎么选：LSM 最容易被审稿人挑刺的环节"
    建模需要负样本，但"没滑坡"占全域 80%~90% 的像元，怎么挑直接决定模型学到什么。**全域随机选**——负样本多落在平坦河谷盆地，模型可能只学会"区分平地与陡坡"而非"区分稳定与潜在不稳定"，随机点还可能落在滑坡体边缘造成标注污染。**只在低坡度"安全区"选**——人为把两类在特征空间拉开，AUC 虚高、成图全域低易发，审稿人一眼识破。**滑坡缓冲区外选**——剔除滑坡点周边一定半径（如 500 m~1 km）内像元再随机选，缓解正负样本空间过近的标注混淆，是目前较认可的折中，但**缓冲半径必须写进报告**，最好做两个半径的敏感性对比。无论哪种：固定随机种子、全程同一份负样本表与同一种切分（空间交叉验证提示见 T5）。

## C.4 分步任务指导（任务书）

### T1 数据采集与统一坐标系

- **做什么**：采集 DEM、岩性、断层、降雨、NDVI、滑坡编目，统一到 CGCS2000/UTM 投影，栅格重采样至 30 m。
- **检查点**：一张"图层清单表"（图层、来源、原始坐标系、目标坐标系、分辨率、重采样方式）+ 研究区边界图。
- **为什么这样做**：这一步产出后面所有步骤的"统一底板"——T3~T5 全部默认"同一像元在各图层中对齐"（理由见 C.3.1）；图层清单表则是报告"数据与方法"一节的核心素材，也是检查坐标系是否统一的第一入口。
- **常见错误与排查**：①类别图层误用双线性重采样——看重采样后唯一值个数是否暴涨；②断层矢量未先投影就做距离变换——距离栅格最大值应与实际跨度同量级；③边界裁剪后 NoData 混入训练表——建表前逐列统计缺失。

!!! tip "经纬度不能直接算距离"
    北纬 26° 附近经度 1° 只有约 100 km、纬度 1° 约 111 km，在经纬度下直接算欧氏距离会让东西向距离被压扁约一成。先投影到 CGCS2000/UTM（单位：米）再做距离变换。

### T2 编目文本结构化提取（LLM）

- **做什么**：用 LLM 从滑坡调查报告提取滑坡点坐标、类型、体积、发生时间，输出 JSON。
- **方法提示**：模板见 C.6.2；报告坐标常为地方坐标系或度分秒，prompt 中要求统一为十进制度 WGS84；体积单位混用（万方/万m³）要统一；提取后与 DEM 边界做空间核查剔除越界点。
- **检查点**：`inventory.json` + 越界/异常点核查记录（越界率 <5%）。
- **为什么这样做**：编目是模型的 Y——Y 错，后面全错。调查报告是半结构化文字，人工转录几百条既慢又易错；LLM 恰好擅长"把非结构化文本映射成固定字段"（[第15章](../ch15.md)），人只负责抽查修正。原始表述保留在 `note` 字段便于回溯。
- **常见错误与排查**：①JSON 前后混入解释文字解析失败——失败段落重试，不要手工硬改；②度分秒（33°28′12″）与十进制度（33.47°）混淆——少样本示例里给一组换算对照；③"万方/万m³"混抄——统一为万 m³ 并在报告说明；④LLM 给无坐标描述"补"出坐标——这是幻觉，宁可 null 交人工补全（C.6.1 规则已强制缺失填 null）。

### T3 因子派生

- **做什么**：派生坡度、坡向、平面曲率、剖面曲率、TWI、距断层距离、降雨侵蚀力 R。
- **方法提示**：按 C.3.2 的公式与函数；每个因子出一张单因子图并做"滑坡点—非滑坡点"箱线对比（肉眼初筛因子区分能力）。
- **检查点**：因子栅格集 + 单因子区分能力箱线图集。
- **为什么这样做**：因子是模型的全部输入来源，"派生"与"初筛"要在训练前完成——箱线图让你建模前就看到哪些因子两条分布几乎重叠，为 T4 提供地学旁证。
- **DEM 分辨率与因子的关系**：坡度、曲率都是"邻域差分"量，分辨率决定邻域的物理尺度——30 m DEM 的"坡度"是 30 m 尺度的平均坡度；越粗地形越被抹平，陡坡变缓、曲率失真，同一地点 12.5 m 与 90 m DEM 的坡度可差好几度。因此：①因子、编目、预测格网必须同分辨率（本案例统一 30 m）；②报告写明 DEM 版本与分辨率——审稿人会问"你的坡度是什么尺度的坡度"。
- **常见错误与排查**：①坡向未当环形量处理（0°与 359°数值差 359°）——按 C.3.2 拆成 $\sin$/$\cos$ 或 8 方向；②示例 DEM 含高斯噪声（见 C.3.4 生成脚本），曲率把噪声放大——派生曲率前轻度平滑（如 `conv2` 配高斯核）并在报告注明；③TWI 的 $A_s$ 需要汇流累积量，拿高程差近似不对——示例数据可暂省略，真实数据走"填洼 → 流向 → 汇流累积"工具链。

### T4 特征选择

- **做什么**：VIF 剔除共线性因子（VIF<10 保留），信息增益排序。
- **方法提示**：VIF 对因子矩阵逐列回归计算；信息增益可用决策树内置重要性或手写计算；排序结果要与已知主控因子（坡度、岩性、降雨）对照。
- **检查点**：因子 VIF 表 + IG 排序表（前 5 因子应包含已知主控因子）。
- **为什么这样做**：候选因子常互相重复（坡度与 TWI 都含坡度、NDVI 与土地利用同源），全塞进模型会让系数失真、分裂选择摇摆；特征选择让因子池"每个都有用、彼此不重复"。
- **多重共线性的直观解释**：把第 $j$ 个因子当因变量、用其余因子回归它，得 $R_j^2$，则 $\mathrm{VIF}_j = 1/(1-R_j^2)$——若 $R_j^2$ 达 0.9，说明它九成的内容别的因子已替它说了。共线的害处是模型"说不清功劳记给谁"，系数与因子重要性随样本扰动大幅漂移。检查工具两件：**相关矩阵热力图**目视找"疑似重复对"（|r|>0.8 警惕），VIF 定量裁决（>10 剔除）。
- **常见错误与排查**：①类别因子未编码就进 VIF 回归——先独热或分级赋值；②剔一个因子后其余 VIF 会变——要**迭代重算**而非一次剔光；③IG 只度量单因子贡献、看不到组合效应——IG 低但机制重要的因子（如距道路距离）可讨论后酌情保留。

### T5 多模型训练与对比

- **做什么**：决策树、随机森林、SVM、kNN 四种模型，10 折交叉验证，AUC 对比（[第07章](../ch07.md)、[第08章](../ch08.md)）。
- **方法提示**：`fitctree`/`TreeBagger`/`fitcsvm`/`fitcknn`；滑坡/非滑坡样本 1:1 配采样（非滑坡点在滑坡点外随机采样）；统一 10 折 `cvpartition` 与同一种非滑坡采样方案，保证模型间可比。
- **检查点**：四模型 AUC/ACC/Kappa 对比表 + ROC 曲线族。
- **为什么这样做**：四种模型"归纳偏好"不同——kNN 靠局部邻居表决（[第07章](../ch07.md)）、决策树靠轴平行分裂、SVM 靠最大间隔、随机森林靠多树投票（[第08章](../ch08.md)）。若 AUC 排名一致、ROC 曲线族形状相近，说明结论是数据的规律而非某模型的偶然发挥；若分歧，分歧本身就是讨论点。这也是[第23章](../ch23.md)文献计量的发现——LSM 高产作者几乎把常用模型都对比过，**多模型对比 + ROC 曲线**因此是 LSM 论文的标准动作。
- **kNN 的"近朱者赤"直觉在空间数据上的特殊风险**：kNN 的假设是"特征相近则同类"（近朱者赤，邻居多数表决）。但空间数据里"相近"有两层——特征相近**且位置相邻**，而相邻位置因子本就高度相似（空间自相关），于是随机 10 折里测试点的"近邻"常是训练点——等于开卷抄答案，AUC/ACC 虚高。提示一个概念：**空间交叉验证**——按空间分块划分折，让测试点与训练点隔开一段距离，测出的才是"外推到没去过的地方"的能力。作业用随机 10 折即可，但建议加跑一组空间分块 CV 对照，写进报告很加分。
- **决策树的过拟合与剪枝**：不设限的树会分裂到每个叶只剩一两个样本，把配准噪声、边界误标当规律——训练集近 100% 而测试集平庸。手段都是第 8 章的老朋友：`MinLeafSize`（5~20 试起）、`MaxNumSplits`，或 `prune` 后剪枝；剪到哪一层以验证集/交叉验证性能为准，不是训练集回代。
- **常见错误与排查**：①各模型用不同随机划分——必须共用同一 `cvpartition` 对象与同一份负样本表；②每折重新选负样本——先定死负样本再切分；③用 `predict` 的 0/1 硬标签算 AUC、做制图——要用**后验概率**（kNN/SVM 开启概率输出选项如 `FitPosterior`）。

### T6 智能体工作流（Function Calling）

- **做什么**：把 T1~T5 封装为工具函数（契约见 C.5.2），LLM 编排。
- **检查点**：完整对话历史 JSON + LLM 中文总结。
- **为什么这样做**：把 T1~T5 固化成 7 个契约函数，一是逼你把每步接口想清楚（接口清楚，换研究区才能零改动）；二是让 LLM 按 ReAct 循环（[第15章](../ch15.md)）调度，形成"思考—调用—观察—再思考"的可复盘流水线，而非一跑完就散的脚本。
- **常见错误与排查**：①系统提示未列全函数签名，LLM 编造工具名——照 C.6.1 列全；②一步塞多个工具调用——规则里强调每步只调一个；③工具抛错后 LLM 编结果——函数返回结构化错误信息，规则要求"失败必须重试或报告，不得编造观察值"。

### T7 制图与地学验证

- **做什么**：最优模型输出概率格网，按 2.5/25/50/75/97.5 百分位分 5 级；与已有地质图易发性分区对比（Kappa）；残差空间分析（误判点是否沿断层/水系聚集）；高易发区滑坡点密度卡方检验。
- **方法提示**：分级阈值写进报告；密度检验对"高易发区 vs 低易发区"的滑坡点密度做 2×2 卡方（p<0.05 为显著）。
- **检查点**：易发性概率图 + 5 级分区图 + Kappa 与密度检验结果。
- **为什么这样做**：制图与验证是 LSM 从"作业"变"作品"的一步。按百分位分 5 级，是因为概率通常强烈右偏（多数像元概率很低），等间距会让"高易发"两级别小到看不见；分位数分级保证每级面积可控、便于防灾资源按级分配（方法取舍详见 C.7）。
- **残差空间分析在查什么**：把"编目点被判为低易发"的误判点标出来看分布——若成串沿断层、水系排布，说明模型系统性低估了某类因子组合（多半是因子池缺构造或水文信息），比笼统的低 AUC 更有诊断价值，直接支撑报告"地质机制解释"一节。
- **常见错误与排查**：①用**训练样本**的概率分布定分位阈值——应用全域预测分布；②把示例数据的占位基准当真实地质图——`ref` 只是高程占位（见 C.6.3），正式报告须换真实基准或声明局限；③2×2 卡方每格期望频数太小——先合并级别再检。

### T8 输出与报告

- **做什么**：模型 AUC 对比表、易发性图集、防灾建议。
- **检查点**：报告含"特征选择的地质依据"与"易发性分区的地质合理性"两节。
- **为什么这样做**：报告的两节硬性要求练的是"翻译"能力——把 VIF/IG 的统计结果翻译回地质语言（坡度、岩性、降雨为何排前，逐项对应 C.1.1 的力学平衡），把 5 级分区图翻译成管理语言（"非常高"区先排查监测、村镇建设参考避让）。防灾建议要落到具体区域与措施，不写"加强监测"式空话。

!!! tip "时间安排建议（10 学时版）"
    T1 占 2 学时、T2 占 1 学时、T3 占 2 学时、T4~T5 占 3 学时、T6 占 1 学时、T7~T8 占 1 学时。

## C.5 参考智能体工作流

### C.5.1 工作流总览

```text
MATLAB LLM 智能体（编排者）
  ├─ load_lsm(study_area)                加载 DEM/编目/因子
  ├─ extract_inventory(text_path)        LLM 从调查报告提取滑坡点
  ├─ derive_factors(DEM)                 派生坡度/坡向/TWI 等
  ├─ select_factors(X, y)                VIF + 信息增益
  ├─ fit_models(X, y, models)            决策树/RF/SVM/kNN + 10折CV
  ├─ make_map(prob_grid)                 概率格网 + 5类分级
  └─ validate(map, geology_ref)          与地质图对比 + 残差空间分析
```

### C.5.2 工具函数契约（需要你实现的函数）

| 函数 | 输入 | 输出 | 职责说明 |
|------|------|------|----------|
| `load_lsm` | study_area | DEM、编目、因子栅格 | 统一投影重采样 |
| `extract_inventory` | 报告文本 | JSON 滑坡点 | LLM 结构化提取 |
| `derive_factors` | DEM | 坡度/坡向/TWI 等栅格 | 地形因子派生 |
| `select_factors` | X, y | 选中因子 | VIF 剔共线 + IG 排序 |
| `fit_models` | X, y, models | 各模型 AUC + 最优模型 | 10 折 CV |
| `make_map` | prob_grid | 分级栅格 | 按 2.5/25/50/75/97.5 百分位分 5 类 |
| `validate` | map, geology_ref | 一致性 Kappa + 残差聚集检验 | 与基准对比 |

对照 C.5.1 看，7 个函数按数据流排成一条链：`load_lsm` 是**数据入口**（读 `data/*.mat`、统一投影与分辨率）；`extract_inventory` 是编目侧旁路（LLM 补编目，在 T2 与主链汇合）；`derive_factors` 把 DEM 加工成因子层；`select_factors` 产出"留谁去谁"的决策；`fit_models` 训练并选最优；`make_map` 把最优模型推回全格网；`validate` 收口出一致性结论。每个函数的输出就是下一个函数的输入约定——接口与上表一致，编排层与实现层就能分头开发、单独调试。

**为什么强调"栅格堆叠（stack）"**：[第07章](../ch07.md)、[第08章](../ch08.md)的建模技术面对的都是"一张 n×p 的表"（行=样本、列=特征），而栅格的原生形态是"一堆同尺寸的二维阵列（每因子一层）"。`load_lsm` 与 `derive_factors` 的隐藏职责，就是把所有因子重采样到**同一格网**后堆叠：训练时抽出编目点与非滑坡点像元的取值构成 n×p 特征矩阵 X 加一列标签 y；预测时对全域每个像元构成 n_total×p 矩阵，一次算出概率再摊回格网。堆叠的前提正是 C.3.1 的坐标统一——**stack 保证"同一行各列取值来自同一地面位置"**，这一句就是 LSM 数据工程的核心。

!!! tip "实现顺序建议"
    先让每个函数在命令行"单测通过"（示例参数能返回约定结构），再接 LLM 编排；函数间用 struct 传数据、字段名与上表一致。先用示例数据跑通全链再换真实数据——顺序反了会同时在调两个问题。

## C.6 Prompt 模板与示例 Prompt 历史

### C.6.1 智能体系统提示词

按附录A的"工具签名 + ReAct 规则"格式改写，工具清单换为 C.5.2 的 7 个函数，并增加本案例特有规则：

```text
规则（新增）：
- 编目提取的坐标须为十进制度 WGS84，越界坐标立即返回 null 并提示人工核查；
- 报告中的"易发性/危险性"判断不得作为模型标签，标签只来自编目点。
```

这两条规则各有"防事故"指向。**坐标规则**防的是 LLM 最危险的失误——幻觉坐标：报告里没坐标时，模型可能"顺手"填一个语法正确、位置却错几百米的经纬度，混进编目后极难察觉；强制"缺失即 null + 人工核查"，把把关权收回人手。**标签规则**防概念偷换：报告里"该点危险性大""建议避让"是调查员的**主观评估**，不是"滑没滑"的事实——被当标签学进去，模型学的是"调查员的措辞习惯"而非滑坡规律。其余通用规则（每步一个工具、严格 JSON、观察值不编造、最后中文总结）沿用附录A的 ReAct 格式；"想"与"做"的分档控制（ToolChoice 的 none/required/auto）见[第15章](../ch15.md)。

### C.6.2 结构化提取模板：滑坡调查报告（`extract_inventory.md` 原版）

```text
# System Prompt
你是地质灾害数据工程师。从滑坡调查报告文本中提取每个滑坡点的结构化信息，
输出 JSON 数组。字段：id, lon, lat, type(崩塌/滑坡/泥石流), volume(万m³),
date(YYYY-MM-DD), trigger(降雨/地震/人工), note。
坐标基于报告所述坐标系（默认 WGS84）。不得编造；缺失填 null。只输出 JSON。

# User Prompt（少样本）
示例："舟曲县东山乡 2010-8-8 发生特大型泥石流，体积约 180 万方，由短时强降雨诱发。"
输出：[{"id":1,"lon":104.37,"lat":33.78,"type":"泥石流","volume":180,
       "date":"2010-08-08","trigger":"降雨","note":"特大型"}]

处理：
<<<
{REPORT_TEXT}
>>>
```

**该模板的调试经验**：坐标常为地方坐标系或度分秒，prompt 中要求统一为十进制度 WGS84；体积单位混用（万方/万m³/吨），统一为万 m³；对无坐标的描述（如"XX 村北坡"），让 LLM 标注 null 并提示人工补全；提取后用 MATLAB 与 DEM 边界做空间核查，剔除越界点。

模板四个部分各司其职，出问题时才知道改哪里：**角色句**（"你是地质灾害数据工程师"）锁定输出立场，压制散文倾向；**字段清单**就是 JSON schema——字段名、类型、"缺失填 null"的约定全在这里，解析失败优先查它；**少样本示例**是"定海神针"——"180 万方 → volume:180"、"2010-8-8 → 2010-08-08"的归一化全靠示例言传身教，新遇到一类单位混乱，最有效的修法就是补一个对照示例；**占位符** `{REPORT_TEXT}` 供程序批量替换，长报告分段填充后合并。

三个高频失败模式：**字段单位**——"万方/万m³"同义可换算，但"吨"是质量不能折成体积，填 null 并在 note 保留原文，宁缺毋编；**坐标格式**——"33°28′12″"换算成 33.47，报告若声明地方坐标系则不换算、坐标填 null 并注明坐标系名待人工转换；**历史调查报告的表述歧义**——"XX 村北坡""公路外侧 200 m"按缺失处理，"约""推测"等措辞在 note 保留原句，不要让 LLM 替你"合理猜测"。

## C.7 结果自检指标

**分类性能**

| 指标 | 说明 | 目标 |
|------|------|------|
| AUC | ROC 曲线下面积 | >0.85 优秀 |
| ACC | 总体准确率 | >0.80 |
| Cohen's Kappa | 与随机一致性对比 | >0.60 |
| TPR/FPR | 真阳/假阳率 | TPR>0.80, FPR<0.25 |

几个指标的直观读法：

- **AUC 的概率解释**：随机抽一个滑坡点与一个非滑坡点，模型给滑坡点打分更高的概率——0.5 是瞎猜，1.0 是完美排序；它不依赖判别阈值，适合"输出概率、用途分级制图"的 LSM。**为何 0.8 良好、0.9 优秀**：LSM 输入是带噪声的环境因子、编目自带配准误差，真实数据 0.85~0.95 已是文献上乘结果；若轻易跑出 0.98+，先查负样本是否选得过易、训练/测试点是否空间过近（数据泄漏），再庆祝。
- **ACC 与类别不平衡**：负样本占八成时"全猜 0"也有 0.8 的 ACC——ACC 只作参考，排序看 AUC，一致性看 Kappa（$\kappa = (p_o - p_e)/(1-p_e)$，扣除"碰巧猜对"的成分）。
- **TPR/FPR 要一起读**：TPR 高说明"该报的报了"，FPR 低才说明"没乱报"；防灾宁肯 FPR 稍高也别漏报，报告要说明按哪个操作点成图。

**基准对比**：随机模型基准（AUC=0.5）与单一因子基准（如仅坡度阈值）；最优模型 AUC 较单一因子基准提升 **≥0.15**。

两层用意：AUC=0.5 查"是否真学到东西"；单一因子基准查"多因子组合是否胜过'只用坡度拍阈值'的朴素经验"——LSM 的价值恰在因子组合的增量，提升不足说明因子池或模型没发挥出来。

**特征选择**：VIF<10 保留；信息增益前 5 因子应包含坡度、岩性、降雨等已知主控因子。

**单因子核查：频率比（FR）**：对每个因子分级（如坡度按 0–10°/10–20°/20–30°/30–45°/>45°），统计每级内"滑坡点占比"与"该级面积占比"之比：

$$\mathrm{FR} = \frac{\text{该级内滑坡点占比}}{\text{该级面积占比}}$$

**FR>1 的区间即"滑坡偏好区间"**：坡度 20–30° 段 FR=3，意为滑坡在该段的富集程度是全域平均的 3 倍。FR 表是 LSM 论文单因子分析的标准表，与 IG 排序互相印证；FR 随坡度的曲线还能检查"倒 U 形"是否存在、是否被模型学出。

**地学验证**：易发性图与已有地质图易发分区一致性 Kappa>0.55；误判点 Moran's I 检验是否沿断层/水系聚集；高易发区滑坡点密度显著高于低易发区（卡方检验 p<0.05）。

三件套各查一事：**Kappa 对比**查"与地质图共识区吻合吗"（扣除碰巧一致，比裸一致率严格）；**Moran's I** 查"误判点是随机散布还是成串聚集"——沿断层、水系成串意味着系统性缺某类信息（接 T7 残差分析）；**密度卡方**查"高易发区滑坡确实更多吗"——易发性图成不成立的"地面真相"检验，也是最有说服力的一件。

**制图分级方法对成图观感的影响**：同一张概率格网，分级方法不同图可完全不同。**等间距**把概率范围均分，分布右偏时绝大多数像元挤在最低一两级、"非常高"区小到近乎不可见；**自然断点（Jenks）**按数据自身聚集间隙切分，图面层次好，但断点随样本变、跨区跨模型不可比；**百分位分级**（本案例采用，2.5/25/50/75/97.5）保证每级像元占比固定，图面均衡且可跨模型比较。无论哪种，**分级阈值必须写进报告**——阅图者需要知道"高易发"对应的概率区间。

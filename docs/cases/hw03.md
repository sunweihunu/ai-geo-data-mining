# 附录C 地貌案例：滑坡敏感性制图（LSM）

> **案例导读**：一场强降雨过后，一条山谷里哪里最容易发生滑坡？滑坡敏感性映射（Landslide Susceptibility Mapping, LSM）用"历史滑坡点 + 环境调节因子"训练分类模型，为全区域每个格点算出滑坡概率，再按概率分级成图，是地质灾害风险分区的基础。本案例以四川冕宁县安宁河流域为研究区，从 DEM 派生地形因子、叠加岩性/降雨/植被等多源数据，经 VIF 与信息增益筛选因子后，用决策树/随机森林/SVM/kNN 四种模型训练对比，把最优模型的概率输出分成 5 级易发性分区图。本案例的方法流程与[第23章 土地篇](../ch23.md)的"六步建模"完全对应——先把书上的流程读懂，再动手实现一遍。

**对应要素**：地貌　|　**难度**：★★　|　**建议学时**：8~12 学时（2~3 人一组）
**方法对应**：[第04章 聚类分析](../ch04.md) · [第07章 k最近邻](../ch07.md) · [第08章 决策树](../ch08.md) · [第23章 地学应用三：土地篇](../ch23.md)

## C.1 案例背景与研究问题

### C.1.1 地学背景

滑坡敏感性映射旨在评估给定区域发生滑坡的**可能性**，是地质灾害风险分区的基础。其影响因素（滑坡调节因子，LCF）包括地形（坡度、坡向、曲率）、水文（降雨、地形湿度指数 TWI）、地质（岩性、断层距离）、土地覆被等。机器学习方法（决策树、随机森林、SVM、kNN）已是 LSM 的主流工具。LSM 回答的是"哪里**容易**发生"（敏感性），与"什么时候发生"（危险性）和"损失多大"（风险）共同构成完整的灾害评估链条。

### C.1.2 研究问题

以某山区为研究区，构建滑坡敏感性概率格网。问题分四层递进：

- **基础问题①（因子构建）**：由 DEM 派生坡度/坡向/TWI，叠加岩性、降雨、NDVI、断层距离等因子；
- **基础问题②（分类建模）**：以滑坡编目为标签（滑坡=1，非滑坡=0），用决策树/随机森林/SVM/kNN 训练二分类模型；
- **基础问题③（特征选择）**：用 VIF、信息增益（IG）筛选因子，避免多重共线；
- **复合问题**：构建"**因子构建 → 特征选择 → 多模型训练 → AUC 对比 → 概率格网制图**"的完整 LSM 工作流，并按概率分 5 类易感性等级。

### C.1.3 地学假设

1. 滑坡发生是地形、地质、水文、植被等因子共同作用的概率事件；
2. 滑坡点与调节因子之间存在统计可分性——历史编目是"大自然做过的实验"；
3. 不同模型对因子非线性关系的刻画能力不同，多模型对比可提升稳健性。

## C.2 学习目标

1. 掌握由 DEM 派生地形因子与多源因子叠加（统一投影坐标系）的方法；
2. 能用 MATLAB 实现决策树、随机森林、SVM、kNN 并做 AUC 评估与 10 折交叉验证；
3. 能用 LLM 从滑坡调查报告提取编目点结构化信息，构建 Function Calling 工作流；
4. 学会 LSM 概率格网制图与易感性分级，并对结果做地质合理性检验。

## C.3 数据集

### C.3.1 主数据集（推荐研究区：四川冕宁县安宁河流域）

| 数据 | 来源 | 分辨率 | 字段 |
|------|------|--------|------|
| DEM | SRTM 30m / ASTER GDEM | 30 m | 高程 |
| 岩性/断层 | 中国地质调查局 1:50 万地质图 | 矢量 | 岩性类型、断层线 |
| 滑坡编目 | 国土资源部地质灾害详查 / 文献 | 点矢量 | 坐标、类型、体积、时间 |
| 降雨 | GPM / CHIRPS | 0.05°/日 | 年降雨、最大日降雨 |
| NDVI | MODIS MOD13 | 250 m/16d | 植被指数 |
| 土地覆被 | GlobeLand30 | 30 m | 类型 |

**坐标系**：统一为投影坐标系 CGCS2000 / UTM Zone 48N（按研究区选分带），所有栅格重采样至 30 m。**坐标系不统一是 LSM 作业最致命的错误**——编目点和因子层错位半个像元，模型学到的是噪声。

**数据获取**：SRTM https://earthexplorer.usgs.gov ；GPM https://gpm.nasa.gov/data ；GlobeLand30 http://www.globallandcover.com ；滑坡编目可用 USGS Landslide Inventory 或文献公开数据替代。

### C.3.2 因子派生要点

- **坡度/坡向/曲率**：由 DEM 用 `gradient`/`surfnorm` 派生；
- **TWI（地形湿度指数）**：$\ln(A_s/\tan\beta)$，$A_s$ 为汇流累积量、$\beta$ 为坡度；
- **距断层距离**：对断层线做欧氏距离变换；
- **降雨侵蚀力 R**：由年降雨经验公式估算。

### C.3.3 备选研究区（四年轮换）

1. **甘肃舟曲白龙江流域**——黄土滑坡、泥石流；
2. **云南小江流域**——崩塌、碎屑流；
3. **三峡库区**——水位涨落诱发滑坡；
4. **福建台风区**——暴雨型滑坡。

## C.4 分步任务指导（任务书）

### T1 数据采集与统一坐标系

- **做什么**：采集 DEM、岩性、断层、降雨、NDVI、滑坡编目，统一到 CGCS2000/UTM 投影，栅格重采样至 30 m。
- **检查点**：一张"图层清单表"（图层、来源、原始坐标系、目标坐标系、分辨率、重采样方式）+ 研究区边界图。

### T2 编目文本结构化提取（LLM）

- **做什么**：用 LLM 从滑坡调查报告提取滑坡点坐标、类型、体积、发生时间，输出 JSON。
- **方法提示**：模板见 C.6.2；报告坐标常为地方坐标系或度分秒，prompt 中要求统一为十进制度 WGS84；体积单位混用（万方/万m³）要统一；提取后与 DEM 边界做空间核查剔除越界点。
- **检查点**：`inventory.json` + 越界/异常点核查记录（越界率 <5%）。

### T3 因子派生

- **做什么**：派生坡度、坡向、平面曲率、剖面曲率、TWI、距断层距离、降雨侵蚀力 R。
- **方法提示**：按 C.3.2 的公式与函数；每个因子出一张单因子图并做"滑坡点—非滑坡点"箱线对比（肉眼初筛因子区分能力）。
- **检查点**：因子栅格集 + 单因子区分能力箱线图集。

### T4 特征选择

- **做什么**：VIF 剔除共线性因子（VIF<10 保留），信息增益排序。
- **方法提示**：VIF 对因子矩阵逐列回归计算；信息增益可用决策树内置重要性或手写计算；排序结果要与已知主控因子（坡度、岩性、降雨）对照。
- **检查点**：因子 VIF 表 + IG 排序表（前 5 因子应包含已知主控因子）。

### T5 多模型训练与对比

- **做什么**：决策树、随机森林、SVM、kNN 四种模型，10 折交叉验证，AUC 对比（[第07章](../ch07.md)、[第08章](../ch08.md)）。
- **方法提示**：`fitctree`/`TreeBagger`/`fitcsvm`/`fitcknn`；滑坡/非滑坡样本 1:1 配采样（非滑坡点在滑坡点外随机采样）；统一 10 折 `cvpartition` 与同一种非滑坡采样方案，保证模型间可比。
- **检查点**：四模型 AUC/ACC/Kappa 对比表 + ROC 曲线族。

### T6 智能体工作流（Function Calling）

- **做什么**：把 T1~T5 封装为工具函数（契约见 C.5.2），LLM 编排。
- **检查点**：完整对话历史 JSON + LLM 中文总结。

### T7 制图与地学验证

- **做什么**：最优模型输出概率格网，按 2.5/25/50/75/97.5 百分位分 5 级；与已有地质图易发性分区对比（Kappa）；残差空间分析（误判点是否沿断层/水系聚集）；高易发区滑坡点密度卡方检验。
- **方法提示**：分级阈值写进报告；密度检验对"高易发区 vs 低易发区"的滑坡点密度做 2×2 卡方（p<0.05 为显著）。
- **检查点**：易发性概率图 + 5 级分区图 + Kappa 与密度检验结果。

### T8 输出与报告

- **做什么**：模型 AUC 对比表、易发性图集、防灾建议。
- **检查点**：报告含"特征选择的地质依据"与"易发性分区的地质合理性"两节。

!!! tip "时间安排建议（10 学时版）"
    T1 占 2 学时、T2 占 1 学时、T3 占 2 学时、T4~T5 占 3 学时、T6 占 1 学时、T7~T8 占 1 学时。

## C.5 参考智能体工作流

### C.5.1 工作流总览

```text
MATLAB LLM 智能体（编排者）
  ├─ load_lsm(study_area)                加载 DEM/编目/因子
  ├─ extract_inventory(text_path)        LLM 从调查报告提取滑坡点
  ├─ derive_factors(DEM)                 派生坡度/坡向/TWI 等
  ├─ select_factors(X, y)                VIF + 信息增益
  ├─ fit_models(X, y, models)            决策树/RF/SVM/kNN + 10折CV
  ├─ make_map(prob_grid)                 概率格网 + 5类分级
  └─ validate(map, geology_ref)          与地质图对比 + 残差空间分析
```

### C.5.2 工具函数契约（需要你实现的函数）

| 函数 | 输入 | 输出 | 职责说明 |
|------|------|------|----------|
| `load_lsm` | study_area | DEM、编目、因子栅格 | 统一投影重采样 |
| `extract_inventory` | 报告文本 | JSON 滑坡点 | LLM 结构化提取 |
| `derive_factors` | DEM | 坡度/坡向/TWI 等栅格 | 地形因子派生 |
| `select_factors` | X, y | 选中因子 | VIF 剔共线 + IG 排序 |
| `fit_models` | X, y, models | 各模型 AUC + 最优模型 | 10 折 CV |
| `make_map` | prob_grid | 分级栅格 | 按 2.5/25/50/75/97.5 百分位分 5 类 |
| `validate` | map, geology_ref | 一致性 Kappa + 残差聚集检验 | 与基准对比 |

### C.6.2 结构化提取模板：滑坡调查报告（`extract_inventory.md` 原版）

```text
# System Prompt
你是地质灾害数据工程师。从滑坡调查报告文本中提取每个滑坡点的结构化信息，
输出 JSON 数组。字段：id, lon, lat, type(崩塌/滑坡/泥石流), volume(万m³),
date(YYYY-MM-DD), trigger(降雨/地震/人工), note。
坐标基于报告所述坐标系（默认 WGS84）。不得编造；缺失填 null。只输出 JSON。

# User Prompt（少样本）
示例："舟曲县东山乡 2010-8-8 发生特大型泥石流，体积约 180 万方，由短时强降雨诱发。"
输出：[{"id":1,"lon":104.37,"lat":33.78,"type":"泥石流","volume":180,
       "date":"2010-08-08","trigger":"降雨","note":"特大型"}]

处理：
<<<
{REPORT_TEXT}
>>>
```

**该模板的调试经验**：坐标常为地方坐标系或度分秒，prompt 中要求统一为十进制度 WGS84；体积单位混用（万方/万m³/吨），统一为万 m³；对无坐标的描述（如"XX 村北坡"），让 LLM 标注 null 并提示人工补全；提取后用 MATLAB 与 DEM 边界做空间核查，剔除越界点。

## C.7 结果自检指标

**分类性能**

| 指标 | 说明 | 目标 |
|------|------|------|
| AUC | ROC 曲线下面积 | >0.85 优秀 |
| ACC | 总体准确率 | >0.80 |
| Cohen's Kappa | 与随机一致性对比 | >0.60 |
| TPR/FPR | 真阳/假阳率 | TPR>0.80, FPR<0.25 |

**基准对比**：随机模型基准（AUC=0.5）与单一因子基准（如仅坡度阈值）；最优模型 AUC 较单一因子基准提升 **≥0.15**。

**特征选择**：VIF<10 保留；信息增益前 5 因子应包含坡度、岩性、降雨等已知主控因子。

**地学验证**：易发性图与已有地质图易发分区一致性 Kappa>0.55；误判点 Moran's I 检验是否沿断层/水系聚集；高易发区滑坡点密度显著高于低易发区（卡方检验 p<0.05）。

**LLM 工作流**：Function Calling 成功率 ≥90%；编目提取坐标越界率 <5%；对话历史可复盘。

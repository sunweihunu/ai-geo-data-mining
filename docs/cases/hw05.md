# 附录E 植被案例：气候变化对 NDVI/EVI 季相时空变化的影响

> **案例导读**：植物什么时候发芽、什么时候落叶，是气候变化的敏感指示器。本案例以青藏高原高寒植被为研究对象，从 NDVI 时序重构入手提取物候参数（生长季起始 SOS、结束 EOS、长度 LOS），用 Sen 斜率 + Mann-Kendall 检验分析物候趋势，用偏相关把绿度变化归因到温度与降雨，再用 PCA + K-means 识别植被响应类型分区，最后用 Transformer 模型预测未来绿度——一条"**物候提取 → 趋势归因 → 分区 → 深度学习预测**"的完整链条。案例横跨[第05章](../ch05.md)降维、[第06章](../ch06.md)线性模型与[第12章](../ch12.md) Transformer，是六个小项目中时序特征最强的一个。

**对应要素**：植被　|　**难度**：★★★　|　**建议学时**：10~14 学时（2~3 人一组）
**方法对应**：[第05章 降维](../ch05.md) · [第06章 线性模型](../ch06.md) · [第12章 深度学习扩展：Transformer](../ch12.md)

## E.1 案例背景与研究问题

### E.1.1 地学背景

植被物候（季相）是气候变化的敏感指示器。NDVI/EVI 时序数据能反映植被绿度与生长季起始（SOS）、结束（EOS）、长度（LOS）的年际变化；气候变化（升温、降雨格局改变）通过影响物候进而影响碳汇、农业产量与生态脆弱性。长时序遥感数据（AVHRR NDVI 1981–至今、MODIS 2000–至今）为物候时空分析提供了基础。对高纬/高寒区，"升温使 SOS 提前、LOS 延长"是被大量观测支持的核心假设——但不同植被类型的响应存在空间异质性，这正是需要数据挖掘的地方。

### E.1.2 研究问题

以某区域植被为对象，分析气候变化对 NDVI/EVI 季相时空变化的影响。问题分四层递进：

- **基础问题①（物候提取）**：对 NDVI 时序做平滑（Savitzky-Golay/HANTS），提取逐年 SOS/EOS/LOS；
- **基础问题②（趋势分析）**：用线性模型/MLL 分析 NDVI 与气候（温度、降雨）的趋势与相关性（[第06章](../ch06.md)）；
- **基础问题③（降维分区）**：对植被像元时序做 PCA/聚类，识别植被响应类型区（[第05章](../ch05.md)）；
- **复合问题**：构建"**物候提取 → 趋势归因 → 分区 → Transformer 预测未来绿度**"的工作流，量化气候变化的贡献。

### E.1.3 地学假设

1. 升温使高纬/高寒区 SOS 提前、LOS 延长；
2. 干旱半干旱区 NDVI 主要受降雨控制；
3. 不同植被类型对气候响应存在空间异质性——可以被聚类识别出来。

## E.2 学习目标

1. 掌握 NDVI 时序平滑（Savitzky-Golay/HANTS）与物候参数提取；
2. 能用 MATLAB 做 Sen 斜率 + Mann-Kendall 趋势分析与偏相关归因；
3. 能用 MATLAB 深度学习工具箱搭建 Transformer 做绿度时序预测；
4. 能用 LLM 从生态站物候观测报告提取验证数据，构建 Function Calling 工作流。

## E.3 数据集

### E.3.1 主数据集（推荐研究区：青藏高原高寒植被）

| 数据 | 来源 | 时间 | 分辨率 | 字段 |
|------|------|------|--------|------|
| NDVI | AVHRR GIMMS / MODIS MOD13 | 1981–2020 | 8d/16d，1 km/8 km | NDVI、EVI |
| 气温降雨 | CRU / ERA5 | 1901– | 月 | 温度、降雨 |
| 土地覆被 | ESA CCI / MCD12Q1 | 1992– | 300 m/500 m | 类型 |
| 物候观测 | 中国物候观测网 CPON | 1980– | 站点 | SOS/EOS 物候期 |

**坐标系**：经纬度 WGS84；栅格统一重采样至 1 km 或 8 km（按区域大小）。

**数据获取**：GIMMS NDVI https://daac.ornl.gov ；MODIS MOD13 https://lpdaac.usgs.gov ；CRU https://crudata.uea.ac.uk ；CPON http://www.cpon.ac.cn 。

### E.3.2 预处理要点

- **去云重构**：NDVI 受云污染严重，用 Savitzky-Golay 或 HANTS 重构——先平滑、后提物候，顺序不能反；
- **物候提取**：动态阈值法（NDVI 增幅达年振幅 20% 定为 SOS）；
- **尺度对齐**：气候（月）与 NDVI（8d/16d）尺度对齐（月→旬插值）。

### E.3.3 备选研究区（四年轮换）

1. **黄土高原**——退耕还林 NDVI 显著上升（人类活动与气候的混合信号，归因更有挑战）；
2. **内蒙古草原**——降雨控制的典型区；
3. **东北森林**——升温影响；
4. **西南喀斯特**——石漠化与植被恢复。

## E.4 分步任务指导（任务书）

### T1 数据采集与预处理

- **做什么**：采集 1981–2020 年 AVHRR/MODIS NDVI + 气温降雨 + 土地覆被，统一坐标系。
- **检查点**：研究区 NDVI 年合成图（4 幅典型年份）+ 数据覆盖表。

### T2 物候观测文本结构化提取（LLM）

- **做什么**：用 LLM 从物候观测报告/生态站年报提取 SOS/EOS 验证数据（JSON）。
- **方法提示**：模板见 E.6.2；物候期表达多样（"5月12日""5月中旬""DOY132"），少样本约束统一为 DOY；"中旬"等模糊表述让 LLM 输出区间中值并标注 note。
- **检查点**：`phenology.json` + DOY 缺失率统计（<15% 达标）。

### T3 时序平滑与物候提取

- **做什么**：Savitzky-Golay 或 HANTS 平滑，动态阈值法提取逐年 SOS/EOS/LOS。
- **方法提示**：平滑窗口先在单像元上试（画原始 vs 平滑曲线对比图）再批量；动态阈值取 NDVI 年振幅的 20%；SOS 用 DOY 表示。
- **检查点**：典型像元平滑对比图 + 研究区多年平均 SOS/EOS/LOS 图。

### T4 趋势与归因分析

- **做什么**：Sen 斜率 + Mann-Kendall 显著性检验逐像元分析；偏相关归因气候贡献（[第06章](../ch06.md)）。
- **方法提示**：Sen 斜率对异常值稳健，适合遥感时序；MK 检验给 p 值，只把 p<0.05 的像元计入"显著趋势面积占比"；偏相关 = 控制温度后 NDVI-降雨的相关，用来分离两气候因子的贡献。
- **检查点**：NDVI 与 SOS 的 Sen 斜率空间图（显著像元占比标注）+ 偏相关图 + 归因统计表。

### T5 降维分区

- **做什么**：PCA + K-means 对像元时序聚类，识别植被响应类型区。
- **方法提示**：对标准化 NDVI 年内曲线聚类（而非原始时序）；k 由轮廓系数与肘部法确定；分区结果与土地覆被类型交叉表对齐（一致性 Kappa>0.5 为佳）。
- **检查点**：响应类型分区图 + 分区—土地覆被交叉表。

### T6 Transformer 预测

- **做什么**：用历史 NDVI + 气候序列预测未来 5 年绿度（[第12章](../ch12.md)）。
- **方法提示**：滑动窗口构造样本（前 12 期 → 后 1 期）；Transformer 编码器结构可从 2 层、4 头起步（MATLAB `transformerLayer`/自建注意力层）；与持续性基准 y(t-12) 对比，RMSE 降低 ≥15% 才算有效；训练集/测试集按时间切分。
- **检查点**：预测—实测曲线 + 与基准的 RMSE 对比 + 模型结构图。

### T7 智能体工作流（Function Calling）

- **做什么**：把 T1~T6 封装为工具函数（契约见 E.5.2），LLM 编排。
- **检查点**：完整对话历史 JSON + LLM 中文总结。

### T8 地学验证

- **做什么**：与生态站物候观测对比（RMSE<10 天）；残差空间分布与土地覆被一致性分析。
- **检查点**：站点验证表（站点、RMSE、Bias）+ 残差空间图（高残差区是否为混合像元/灌溉区/扰动区）。

### T9 输出与报告

- **做什么**：物候趋势图、响应分区图、Transformer 预测曲线；撰写报告与生态保护建议。
- **检查点**：报告含"趋势的气候归因"与"分区响应差异"两节。

!!! tip "时间安排建议（12 学时版）"
    T1~T2 占 2 学时、T3 占 2 学时、T4 占 2 学时、T5 占 1 学时、T6 占 3 学时、T7~T9 占 2 学时。Transformer 训练耗时较长，建议在 T3~T5 完成后就启动 T6 的环境搭建与试训练。

## E.5 参考智能体工作流

### E.5.1 工作流总览

```text
MATLAB LLM 智能体（编排者）
  ├─ load_ndvi(study_area, period)           加载 NDVI+气候
  ├─ extract_phenology_report(text_path)     LLM 提取生态站物候验证
  ├─ smooth_ts(NDVI)                         SG/HANTS 重构
  ├─ extract_phenology(NDVI_smooth)          SOS/EOS/LOS
  ├─ trend_mk(series)                        Sen 斜率 + Mann-Kendall
  ├─ cluster_pixel(NDVI_ts)                  PCA+K-means 响应分区
  ├─ transformer_forecast(NDVI, climate)     未来绿度预测
  └─ validate(sos_pred, sos_obs)             与生态站对比+残差空间
```

### E.5.2 工具函数契约（需要你实现的函数）

| 函数 | 输入 | 输出 | 职责说明 |
|------|------|------|----------|
| `load_ndvi` | study_area, period | NDVI + 气候栅格 | 统一坐标系 |
| `extract_phenology_report` | 报告文本 | JSON 物候期 | LLM 结构化提取 |
| `smooth_ts` | NDVI | 平滑时序 | SG/HANTS |
| `extract_phenology` | NDVI_smooth | SOS/EOS/LOS | 动态阈值法 |
| `trend_mk` | series | Sen 斜率 + p 值 | 趋势显著性 |
| `cluster_pixel` | NDVI_ts | 响应类型区 | PCA + K-means |
| `transformer_forecast` | NDVI, climate | 未来绿度 | Transformer 序列预测 |
| `validate` | sos_pred, sos_obs | RMSE + 残差空间 | 生态站验证 |

!!! note "smooth_ts 的工具箱说明"
    `smooth_ts` 默认用 base MATLAB 的 `smoothdata('gauss')`（无需额外工具箱）；若装有 Signal Processing Toolbox，可将方法切换为 Savitzky-Golay（`sgolay`）。

## E.7 结果自检指标

**物候提取精度**

| 指标 | 说明 | 目标 |
|------|------|------|
| RMSE(SOS) | 与生态站对比 | <10 天 |
| R²(SOS) | 时序相关 | >0.5 |
| Bias | 系统偏差 | \|Bias\|<5 天 |

**趋势分析**：Sen 斜率显著性（MK 检验 p<0.05 的像元占比，需报告占比值）；与已知气候趋势方向一致区域占比 >70%。

**Transformer 预测**

| 指标 | 说明 | 目标 |
|------|------|------|
| RMSE(预测) | 测试集 | <0.05 NDVI |
| R²(预测) | 决定系数 | >0.65 |
| 优于持续性基准 | 较 y(t-12) | RMSE 降低 ≥15% |

**降维分区**：轮廓系数 >0.4；分区与土地覆被类型一致性 Kappa>0.5。

**地学验证**：残差空间分布——高残差区是否为混合像元/灌溉区/扰动区；物候验证的站点级合理性。

**LLM 工作流**：Function Calling 成功率 ≥90%；物候报告提取 DOY 缺失率 <15%；对话历史可复盘。

# 大作业案例总纲

> **本栏目导读**：从本页起进入本书的**案例附录篇**。正文各章解决"方法是什么、怎么用"的问题，本篇回答的是"拿到一个真实地学问题，怎样把方法串成一件完整的作品"。我们围绕**自然地理六大要素**（水文、气候、地貌、土壤、植被、动物）设计了六个课后案例项目与一个期末综合大作业，每个案例都由若干基础数据挖掘问题复合而成，并要求使用 MATLAB LLM 工具箱接口构建智能体工作流，形成可复现脚本与 Prompt 模板。学完正文再做完本篇，你应当具备独立完成一项"数据 + 方法 + 地学验证 + AI 协作"全流程小课题的能力。

**对应章节**：全书各章（每个案例首段均标注了对应的章节）　|　**适用对象**：《数据挖掘》（地学方向）本科生　|　**组织方式**：2~3 人一组，期末大作业 3~4 人一组

## 0 本篇的定位与用法

本书正文按"方法"组织——聚类、降维、线性模型、kNN、决策树、神经网络、SVM、深度学习、Transformer、LLM；实际科研与生产中遇到的问题却按"对象"组织——一条河的径流怎么预报、一片山哪里容易滑坡、一座城的热岛怎么缓解。附录篇就是两者之间的"接线板"：每个案例从一条真实的地学问题出发，把它拆成若干个你在正文里已经学过的**基础问题**（回归、分类、聚类、降维、特征选择），再复合成一个**综合问题**，最后统一纳入 **LLM 智能体工作流**完成。

每个案例页面的结构是固定的，便于按需查阅：

| 小节 | 内容 | 用法 |
|------|------|------|
| 案例背景与研究问题 | 地学背景、基础问题与复合问题、地学假设 | 开题前精读，报告"问题定义"一节的素材 |
| 数据集 | 主数据集字段与来源、预处理要点、备选研究区、示例数据生成 | 建数据目录时对照 |
| 分步任务指导 | T1…T9 逐级任务、方法提示、检查点 | 每完成一步核对一次 |
| 参考智能体工作流 | 工作流图、需要你实现的工具函数契约 | 设计 `main.mlx` 与 Function 前对照 |
| Prompt 模板与示例历史 | 系统提示词、结构化提取模板、一段可复盘的示例对话 | 直接改写复用，勿从零开始 |
| 结果自检指标 | 各项量化指标与目标值 | 提交前自检（评分标准由教师掌握） |
| 提交要求 | 目录结构与提交物清单 | 打包前核对 |

## 3 通用智能体工作流要求（所有案例共同遵循）

无论哪个案例，最终交付的智能体工作流都必须包含以下 **6 个环节**，并形成可复现脚本与 Prompt 模板：

1. **问题定义**——含地学背景与研究假设，写在报告开头；
2. **数据采集与预处理**——明确数据来源、时间范围与坐标系，统一尺度；
3. **AI 辅助建模**——列出 Prompt 与对话历史，使用 MATLAB LLM 工具箱接口完成模型 API 调用；
4. **结果地学验证**——对比基准/地面观测数据，做残差空间分析；
5. **解释关键地理变量的物理意义**——把统计结果翻译回地学机制；
6. **政策/管理建议或可视化产品**——地图、图表或交互仪表板。

配套的 **MATLAB LLM 工具箱使用要求**：

- 通过 `webwrite` / `matlab.net.http` 或 MathWorks 官方接口调用 LLM 服务（GPT 系列、DeepSeek、通义千问等兼容 OpenAI 协议的接口均可），参见[第15章](../ch15.md)；
- 完成**结构化数据提取**：让 LLM 从非结构化文本（水文年鉴、气象公报、滑坡编目报告、土种志、调查记录）中抽取结构化字段（JSON）；
- 完成 **Function Calling**：把自己编写的 MATLAB 函数注册为 LLM 可调用的工具（如 `load_discharge`、`fit_forecast`、`plot_residual_map`），由 LLM 决定调用顺序，构成"思考—调用—观察—再思考"的 ReAct 循环；
- 总结调用经验，形成**可复用的 Prompt 模板**（每个案例提供模板与少样本示例，换研究区后应无需大改）。

## 4 快速开始：示例数据一键生成

每个案例都自带示例数据生成脚本 `gen_demo_data.m`，无需联网下载任何外部数据，即可在本机生成带有合理地学信号的练习数据（例如径流受当月及前两月降雨驱动、滑坡点偏向陡坡、城区地表温度偏高数摄氏度），供开发与调试全流程使用。以附录A为例：

```matlab
% 在 MATLAB 中
cd '<案例目录>'        % 必须先 cd 到案例工作目录
gen_demo_data          % ① 生成 data/ 下的示例 .mat 数据
```

各案例的生成脚本可从案例页"数据集"一节直接下载。生成脚本中注入的信号强度保证了模型能训出有意义的结果（R²>0、AUC>0.5），而不是仅仅"不报错"——请把示例数据当作**开发环境**，正式实验切换到真实数据时，只需按数据集说明的字段整理同名 `.mat` 文件覆盖 `data/` 目录，你的全部代码无需改动。

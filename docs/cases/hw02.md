# 附录B 气候案例：极端气候事件预测与可解释性

> **案例导读**：强降水、高温热浪、干旱、寒潮——极端气候事件影响巨大，而中长期（延伸期 10–30 天）的数值预报技巧有限。本案例以华南前汛期强降水为预测目标，走一条"**降维 → 预测 → 解释**"的技术路线：先对 500 hPa 高度场与海温场做 EOF 降维提取物理模态，再用决策树/SVM 预测下一季是否发生极端事件，最后用决策树规则与特征重要性做可解释性分析，并请 LLM 用气候动力学知识逐条"审规则"。可解释性是本案例区别于一般分类作业的灵魂：模型给出的每条规则都要能讲出气候学机制。

**对应要素**：气候　|　**难度**：★★　|　**建议学时**：8~12 学时（2~3 人一组）
**方法对应**：[第05章 降维](../ch05.md) · [第08章 决策树](../ch08.md) · [第10章 支持向量机](../ch10.md) · [第22章 地学应用二：气象篇](../ch22.md)

## B.1 案例背景与研究问题

### B.1.1 地学背景

极端气候事件（强降水、高温热浪、干旱、寒潮）对社会经济与生态环境影响巨大。其发生与大气环流异常（北极涛动 AO、欧亚遥相关 EU 等）、海温异常（ENSO、印度洋偶极子 IOD）、青藏高原加热、中高纬积雪等前兆因子密切相关。[第22章](../ch22.md) 讲过，数值天气预报在延伸期的技巧有限，而机器学习可以从多源数据中挖掘**非线性遥相关关系**：前冬的海温/环流模态与次年汛期的极端事件之间，往往存在滞后数月的统计联系——预报窗口恰恰落在数值模式最弱、统计方法最强的时段。

### B.1.2 研究问题

以某区域极端气候事件为预测目标，问题分四层递进：

- **基础问题①（降维）**：对高维环流场/海温场做 PCA/EOF 降维，提取主模态及其时间系数作为预报因子（[第05章](../ch05.md)）；
- **基础问题②（分类预测）**：用决策树/SVM 预测未来一季是否发生极端事件（二分类）及强度等级（多分类）（[第08章](../ch08.md)、[第10章](../ch10.md)）；
- **基础问题③（可解释性）**：用决策树规则、特征重要性、SHAP 思路解释模型，识别关键前兆因子；
- **复合问题**：构建"**EOF 降维 + SVM 预测 + 决策树解释**"的可解释极端气候预测工作流。

### B.1.3 地学假设

1. 极端事件与前兆海温/环流模态存在可检测的遥相关（滞后相关）；
2. 不同类型极端事件（旱 vs 涝）的关键前兆因子不同；
3. 可解释模型揭示的因子符合已知气候动力学机制——**可以被气候学知识检验**。

## B.2 学习目标

1. 掌握 EOF/PCA 对气象场降维的方法与物理模态解释（注意面积加权与去季节循环）；
2. 能用 MATLAB 实现决策树、SVM 并做超参数网格寻优；
3. 能用 LLM 完成气象公报文本提取与 Function Calling 工作流；
4. 学会可解释性分析，并用气候学知识交叉验证模型规则。

## B.3 数据集

### B.3.1 主数据集（推荐研究区：华南前汛期强降水）

| 数据 | 来源 | 时间 | 分辨率 | 字段 |
|------|------|------|--------|------|
| 强降水事件 | 国家气候中心气候公报 / 灾情数据库 | 1980–2020 | 事件级 | 时间、区域、过程雨量 |
| 500 hPa 高度场 | NCEP/NCAR 再分析 | 1948– | 月 | 格点 gpm，2.5°×2.5° |
| 海表温度 SST | NOAA ERSST/OISST | 1854– | 月 | 格点 ℃，2°×2° |
| 环流指数 | 国家气候中心 74 项 | 1951– | 月 | AO、EU、副高等 |
| 降水格点 | CN05.1 / CRU | 1961– | 月 | mm，0.5°×0.5° |

**坐标系**：经纬度网格 WGS84；事件级数据需空间化到格点。

**数据获取**：NCEP/NCAR https://psl.noaa.gov/data/gridded/data.ncep.reanalysis.html ；NOAA ERSST https://www.ncei.noaa.gov/products/extended-reconstructed-sst ；国家气候中心 http://cmdp.ncc-cma.net 。

### B.3.2 预处理要点

- **极端事件定义**要写进报告：强降水取日降水 >95 百分位；高温热浪取连续 ≥3 日 Tmax>35 ℃；
- **EOF 前的规矩**：去季节循环（逐月求距平）、标准化、**面积加权**（乘 √cos φ）——不加权的高纬格点会虚高方差，这是气象场 EOF 最经典的错误；
- **滞后配置**：前冬（DJF）因子 → 次年汛期（JJAS）事件，滞后相关筛选前兆。

### B.3.3 备选研究区（四年轮换）

1. **长江中下游梅雨异常**——关注副高脊线、EU 遥相关；
2. **华北夏季高温热浪**——关注大陆高压、土壤湿度；
3. **西南秋旱**——关注印度洋偶极子 IOD、青藏高原积雪；
4. **东北夏季低温冷害**——关注鄂霍次克海阻塞高压。

## B.4 分步任务指导（任务书）

### T1 数据采集与预处理

- **做什么**：采集 1980–2020 年研究区极端事件记录与同期环流/海温场，统一为 WGS84 经纬度网格。
- **检查点**：事件年表（每年事件次数与强度）+ 因子场清单（变量、层次、分辨率、时段）。

### T2 公报文本结构化提取（LLM）

- **做什么**：用 LLM 从气象灾情公报提取极端事件的发生时间、地点、强度，输出 JSON。
- **方法提示**：模板见 B.6.2；公报中"区域性暴雨过程"常带起止日期与过程雨量，字段设计要能容纳；地点写法（"桂北""珠江三角洲"）需规划好空间化的字典。
- **检查点**：`events.json` + 与格点降水序列的交叉核查记录。

### T3 EOF 降维

- **做什么**：对 500 hPa 高度场、SST 分别做经验正交函数分解，取前 N 个主模态的时间系数作为因子。
- **方法提示**：按 B.3.2 的规矩预处理后，把格点场按时间×空间摊平再做 `pca`/SVD；North 准则检验模态可分性；结合空间模态图给每个 PC 起物理名字（如"副高强度模态"）。
- **检查点**：前 10 模态方差解释率表 + 前 3~4 个模态的空间图与时间系数图（每图有物理命名）。

### T4 决策树/SVM 预测

- **做什么**：滞后相关筛选前兆因子 → 训练决策树与 SVM → 网格搜索超参数 → 输出分类性能。
- **方法提示**：决策树限制最大深度（可解释性优先）；SVM 用 RBF 核，对 C、γ 做网格搜索（`fitcsvm` + `OptimizeHyperparameters` 或手写网格）；样本不平衡时用类别权重；交叉验证用按年分块的 `cvpartition`，避免同一年的样本跨训练/测试泄漏。
- **检查点**：ACC/AUC/F1 对比表 + ROC 曲线 + 最优超参数记录。

### T5 可解释性分析

- **做什么**：导出决策树规则、特征重要性；用 LLM 解释每条规则的气候学意义并判断合理性。
- **方法提示**：`fitctree` 的 `view`/`exportTree` 导出规则；规则数控制在 ≤15 条、单条规则样本覆盖 ≥10；把 PC 编号连同其空间模态说明一起交给 LLM（见 B.6.2），否则 LLM 无法把抽象 PC 对应到气候模态。
- **检查点**：规则—解释对照表（规则、类别、LLM 解释、plausible 判定）。

### T6 智能体工作流（Function Calling）

- **做什么**：把 T1~T5 封装为工具函数（契约见 B.5.2），LLM 编排全流程。
- **检查点**：完整对话历史 JSON + LLM 中文总结。

### T7 地学验证

- **做什么**：与气候学基准（持续性基准、ENSO 阈值基准）对比；误报/漏报的空间分布分析；分年代 skill 稳定性检验。
- **方法提示**：ENSO 阈值基准 = Niño3.4 超阈值即预报事件发生；把误报/漏报画在地图上，看是否在地形或海岸带聚集；滑动 10 年窗口统计 ACC 的标准差。
- **检查点**：基准对比表（要求 ACC 较两基准提升 ≥5%）+ 残差空间图 + skill 稳定性曲线。

### T8 输出与报告

- **做什么**：预测准确率、ROC、决策树规则图、关键前兆因子地图；撰写报告。
- **检查点**：报告须有"可解释性"专节——这是本案例的核心得分点，也是教师评分的重点（评分细则由教师掌握）。

!!! tip "时间安排建议（10 学时版）"
    T1 占 2 学时、T2 占 1 学时、T3 占 2 学时、T4 占 2 学时、T5~T6 占 2 学时、T7~T8 占 1 学时。若公报文本获取困难，可自拟 5~10 段仿真公报练手 T2。

## B.5 参考智能体工作流

### B.5.1 工作流总览

```text
MATLAB LLM 智能体（编排者）
  ├─ load_climate(region, period)        加载环流/海温/事件
  ├─ extract_bulletin(text_path)         LLM 从气候公报提取事件
  ├─ eof_decompose(field, n_mode)        EOF 降维取主模态
  ├─ select_precursor(X, y, lag)         滞后相关选前兆因子
  ├─ fit_predict(X, y, model)            决策树/SVM 预测
  ├─ explain_rules(model, X)             LLM 解释规则与特征重要性
  └─ validate(y_true, y_pred)            对比基准 + 残差空间分析
```

### B.5.2 工具函数契约（需要你实现的函数）

| 函数 | 输入 | 输出 | 职责说明 |
|------|------|------|----------|
| `load_climate` | region, period | struct（场 + 事件标签） | 加载并面积加权预处理 |
| `extract_bulletin` | 公报文本路径 | JSON 事件列表 | LLM 结构化提取（模板见 B.6.2） |
| `eof_decompose` | field, n_mode | PC 时间系数、EOF 空间模态 | 经验正交函数分解 |
| `select_precursor` | X, y, lag | 选中因子 + 滞后阶数 | 滞后相关筛选 |
| `fit_predict` | X, y, model | 预测标签 + 模型对象 | 决策树/SVM，含网格搜索 |
| `explain_rules` | model, X | 规则文本 + 重要性 + LLM 解释 | 规则导出与气候学解释 |
| `validate` | y_true, y_pred | ACC/AUC + 残差空间分析 | 与气候学基准对比 |

**模板二：决策树规则气候学解释**（`explain_rules.md` 原版）

```text
# System Prompt
你是气候动力学专家。给定一棵决策树的若干规则（条件→类别）和对应的特征名
（如 PC5、Niño3.4、AO 指数），请用气候学知识解释每条规则的物理意义，并判断
是否符合已知机制。输出 JSON：
[{"rule":"PC5>0.8 & Niño3.4>0.5","class":"强降水","explanation":"...","plausible":true}]
解释应涉及：海温异常→大气环流响应→水汽输送/抬升条件。不得编造机制。

# User Prompt
特征说明：
- PC5：500hPa 高度场 EOF 第5模态时间系数（副高位置模态）
- Niño3.4：赤道中东太平洋海温指数
- AO：北极涛动指数

决策树规则：
1. PC5>0.8 & Niño3.4>0.5 → 强降水
2. PC5<=-0.3 & AO>0.5 → 正常
3. Niño3.4<-0.6 → 干旱

请解释。
```

**该模板的调试经验**：先用 LLM 把抽象 PC 编号与已知气候模态对应（要连同 EOF 空间图一起给）；解释需引用具体机制（沃克环流、P-J 型遥相关等），避免空泛；对不符合机制的规则标记 `plausible:false`，提示可能过拟合。

## B.7 结果自检指标

**分类性能**

| 指标 | 说明 | 目标 |
|------|------|------|
| ACC | 总体准确率 | >0.70 |
| AUC | ROC 曲线下面积 | >0.78 |
| F1 | 精确率/召回率调和 | >0.65（正负类均衡时） |
| FAR | 虚警率 | <0.30 |
| POD | 命中率 | >0.70 |

**基准对比**：持续性基准（上一年同类事件状态）与 ENSO 阈值基准（Niño3.4 超阈值即预报）；SVM/决策树的 ACC 较两基准提升 **≥5%**。

**可解释性**：决策树规则数 ≤15，单条规则样本覆盖 ≥10；LLM 解释与气候学机制一致性（教师/专家判定，3 级）；特征重要性与滞后相关系数排序一致（Spearman ρ>0.6）。

**地学验证**：误报/漏报是否有地形或海岸带聚集；不同年代 skill 稳定性（滑动窗口 ACC 标准差 <0.12）。

**LLM 工作流**：Function Calling 成功率 ≥90%；对话历史可复盘；规则解释模板跨事件可复用。

# 附录F 动物案例：物种分布建模与生物多样性

> **案例导读**：只在一个 fraction 的山林里有人见到过川金丝猴，整个西南山地哪里还有适合它生存的环境？气候变暖后它的家园会往哪里缩？物种分布建模（Species Distribution Modeling, SDM）用已知出现点与环境变量（气候、地形、植被、人类活动）的关系回答这两个问题，是保护生物学与生态地理学的核心工具。本案例以川金丝猴为对象，从 GBIF 与调查报告中汇集出现点、生成伪缺失点，用 kNN/决策树/SVM/随机森林四种模型建立生态位模型，叠加多物种预测识别生物多样性热点，并用 CMIP6 未来气候情景预测分布变迁、提出保护区规划建议。

**对应要素**：动物　|　**难度**：★★★　|　**建议学时**：10~14 学时（2~3 人一组）
**方法对应**：[第07章 k最近邻](../ch07.md) · [第08章 决策树](../ch08.md) · [第10章 支持向量机](../ch10.md) · [第05章 降维](../ch05.md)

## F.1 案例背景与研究问题

### F.1.1 地学背景

物种分布建模通过"出现点 × 环境变量"的关系估计物种的**生态位**，再投影回地理空间得到潜在分布图，是保护生物学与生态地理学的核心工具；代表性方法有 MaxEnt、GLM、随机森林、SVM、kNN 等。气候变化背景下，预测物种分布的变迁方向（一般向高纬/高海拔迁移）对保护区规划意义重大。SDM 有两个绕不开的数据问题：**出现点只是"有记录"而非"没分布"**（需要生成伪缺失点），以及记录点天然偏向交通便利区（采样偏差，需要清洗与解释）。

### F.1.2 研究问题

以某物种或类群为对象，建模其分布并评估生物多样性热点。问题分四层递进：

- **基础问题①（建模）**：用 kNN/决策树/SVM/RF 建立物种存在—环境关系模型；
- **基础问题②（伪缺失点）**：在出现点之外按距离/环境分层随机生成伪缺失点，处理样本不平衡；
- **基础问题③（多样性热点）**：对多物种的适宜性预测叠加，识别物种丰富度热点；
- **复合问题**：构建"**出现点提取 → 特征构建 → 多模型对比 → 未来气候情景下分布变迁预测 → 保护区建议**"工作流。

### F.1.3 地学假设

1. 物种分布受气候、地形、植被、人类活动共同制约（生态位理论）；
2. 出现点—环境关系可外推到无数据区与未来情景（假设生态位保守、物种能跟随）；
3. 生物多样性热点与环境异质性、栖息地连通性相关。

## F.2 学习目标

1. 掌握物种分布建模的数据准备：出现点清洗、伪缺失点生成、环境变量选择；
2. 能用 MATLAB 实现 kNN/决策树/SVM/RF 并做 AUC 评估，处理样本不平衡；
3. 能用 LLM 从物种调查/标本记录提取出现点，构建 Function Calling 工作流；
4. 学会气候变化情景下的分布变迁预测与保护区规划建议。

## F.3 数据集

### F.3.1 主数据集（推荐研究对象：川金丝猴 / 滇金丝猴）

| 数据 | 来源 | 分辨率 | 字段 |
|------|------|--------|------|
| 物种出现点 | GBIF / iNaturalist / 全国陆生野生动物调查 | 点 | 经纬度、日期、海拔 |
| BIOCLIM 气候 | WorldClim / CHELSA | 1 km | BIO1–19 温度降雨衍生变量 |
| 未来气候 | CMIP6（SSP245/585） | 1 km | 同 BIOCLIM |
| DEM | SRTM | 30 m | 高程、坡度 |
| 土地覆被 | ESA WorldCover | 10 m | 类型 |
| 人类活动 | Human Footprint / 夜间灯光 | 1 km | 干扰强度 |

**坐标系**：经纬度 WGS84，栅格重采样至 1 km。

**数据获取**：GBIF https://www.gbif.org ；WorldClim https://www.worldclim.org ；CMIP6 https://esgf-node.llnl.gov ；Human Footprint https://doi.org/10.5061/dryad.052q5 。

### F.3.2 预处理要点

- **出现点清洗**：去重、坐标精度过滤、环境异常点剔除（如海拔为负的点）；
- **伪缺失点**：距出现点 ≥ 某距离，或按环境分层随机生成——生成策略本身就是设计决策，要写进报告；
- **样本不平衡**：类别加权或 SMOTE 重采样，处理后 AUC 稳定（变化 <0.05）才说明策略可靠。

### F.3.3 备选研究对象（四年轮换）

1. **大熊猫**——经典旗舰种，栖息地破碎化；
2. **藏羚羊**——高原迁徙，气候变化敏感；
3. **中华白海豚**——海岸带，人类活动干扰（海洋环境变量）；
4. **某候鸟（如白头鹤）**——迁徙候鸟，季节动态。

生成的 `data/川金丝猴_西南山地.mat`：

| 变量 | 说明 |
|------|------|

| `env` / `envNames` | 150×150 格网环境变量矩阵与名称，列顺序 [BIO1_temp, BIO12_precip, BIO4_seas, BIO15_alt, BIO3_iso] |

## F.4 分步任务指导（任务书）

### T1 数据采集与预处理

- **做什么**：采集物种出现点（GBIF/iNaturalist）+ BIOCLIM 气候变量 + DEM + 土地覆被 + 人类活动，统一坐标系。
- **方法提示**：GBIF 可用 `webread` 调 API 按学名拉取；出现点按 F.3.2 清洗；环境变量挑选有生态学依据（温度/降雨/植被/干扰各留代表，避免 19 个 BIOCLIM 全上）。
- **检查点**：出现点分布图（叠加环境底图）+ 环境变量选择依据表。

### T2 调查报告文本结构化提取（LLM）

- **做什么**：用 LLM 从物种调查报告/志书提取出现点坐标、海拔、观测日期（JSON）。
- **方法提示**：模板见 F.6.2；报告坐标常为"E/N"格式或度分秒，少样本约束统一十进制度；海拔缺失让 LLM 标 null 后用 DEM 补全；物种名统一学名（避免同物异名）。
- **检查点**：`occurrences.json` + 坐标越界/异常率统计（<10% 达标）。

### T3 伪缺失点生成

- **做什么**：在出现点外按距离/环境分层随机生成伪缺失点。
- **方法提示**：距离阈值（如 ≥10 km）与环境分层（把环境空间分箱后按箱生成）两种策略都实现，对比结果稳定性；伪缺失数量取出现点的 1~3 倍。
- **检查点**：伪缺失点分布图 + 两种策略的对比说明。

### T4 多模型对比

- **做什么**：kNN/决策树/SVM/RF 四种模型，处理样本不平衡（加权/重采样），AUC 评估（[第07章](../ch07.md)、[第08章](../ch08.md)、[第10章](../ch10.md)）。
- **方法提示**：`fitcknn`/`fitctree`/`fitcsvm`/`TreeBagger`；空间分组交叉验证（按流域/网格分块）防空间泄漏；报告单因子基准（仅 BIO1 年均温）以便对比。
- **检查点**：四模型 AUC/TSS/ACC 对比表 + ROC 曲线族 + 最优超参数记录。

### T5 多物种叠加

- **做什么**：预测各物种适宜性图，叠加得物种丰富度热点。
- **方法提示**：适宜性概率阈值化（如 >0.5 记该物种存在）后逐像元求和；没有多物种数据时，可用同一物种的多个模型输出做"模型间一致性图"替代练习。
- **检查点**：丰富度热点图 + 热点区与保护区叠加统计。

### T6 未来情景预测

- **做什么**：用 CMIP6 未来气候（SSP245/585）驱动模型，预测分布变迁。
- **方法提示**：对环境矩阵的温度列加情景升温扰动（示例数据约定第 1 列为 BIO1）；统计适宜面积变化率与分布重心迁移方向；**变迁方向要与物种生态位已知趋势对照**（向高纬/高海拔迁移是否出现）。
- **检查点**：当前/未来适宜性对比图 + 面积变化率表 + 重心迁移矢量。

### T7 智能体工作流（Function Calling）

- **做什么**：把 T1~T6 封装为工具函数（契约见 F.5.2），LLM 编排。
- **检查点**：完整对话历史 JSON + LLM 中文总结。

### T8 地学验证与输出

- **做什么**：与独立出现点/保护区分布对比（重叠率 >60%）；误判点空间分析（是否在栖息地破碎区/人类活动区聚集）；输出适宜性图、多样性热点图、未来分布变迁图；撰写报告与保护区规划建议。
- **检查点**：验证统计表 + 图件三件套 + 报告含"生态位机制解释"与"保护区建议"两节。

!!! tip "时间安排建议（12 学时版）"
    T1~T2 占 3 学时、T3 占 1 学时、T4 占 3 学时、T5 占 1 学时、T6 占 2 学时、T7~T8 占 2 学时。

## F.5 参考智能体工作流

### F.5.1 工作流总览

```text
MATLAB LLM 智能体（编排者）
  ├─ load_species(species, region)          加载出现点+环境变量
  ├─ extract_occurrence(text_path)          LLM 从调查报告提取出现点
  ├─ gen_pseudo_abs(present, env)           生成伪缺失点
  ├─ fit_sdm(X, y, models)                  kNN/决策树/SVM/RF 对比
  ├─ predict_suitability(model, env_grid)   适宜性格网
  ├─ richness_overlay(species_maps)         物种丰富度热点
  ├─ future_shift(model, future_climate)    未来情景分布变迁
  └─ validate(map, reserve)                 与保护区对比+残差空间
```

### F.5.2 工具函数契约（需要你实现的函数）

| 函数 | 输入 | 输出 | 职责说明 |
|------|------|------|----------|
| `load_species` | species, region | 出现点 + 环境变量 | 统一坐标系 |
| `extract_occurrence` | 报告文本 | JSON 出现点 | LLM 结构化提取 |
| `gen_pseudo_abs` | present, env | 伪缺失点 | 距离/环境分层随机 |
| `fit_sdm` | X, y, models | AUC + 最优模型 | 处理不平衡 |
| `predict_suitability` | model, env_grid | 适宜性栅格 | 概率格网 |
| `richness_overlay` | species_maps | 丰富度栅格 | 多物种叠加 |
| `future_shift` | model, future_climate | 未来适宜性 + 变迁 | SSP 情景 |
| `validate` | map, reserve | 重叠率 + 残差空间 | 与保护区对比 |

### F.6.2 结构化提取模板：物种调查报告出现点（`extract_occurrence.md` 原版）

```text

输出 JSON 数组。字段：id, species, lon, lat, elevation_m, date(YYYY-MM-DD),

       "date":"2019-05","location_desc":"卧龙自然保护区","observer":"孙某等","note":""}]

处理：
<<<
{REPORT_TEXT}
>>>
```

**该模板的调试经验**：报告坐标常为"E/N"格式或度分秒，少样本约束统一十进制度；海拔常缺失，LLM 标注 null 后用 DEM 补全；物种名需统一学名（避免同物异名），可在 prompt 中给出学名映射；提取后用 MATLAB 与 BIOCLIM 范围做环境合理性核查，剔除异常点。

## F.7 结果自检指标

**SDM 性能**

| 指标 | 说明 | 目标 |
|------|------|------|
| AUC | ROC 曲线下面积 | >0.80 合格，>0.90 优秀 |
| TSS | 真技能统计量 | >0.5 |
| ACC | 总体准确率 | >0.75 |
| Boyce 指数 | 预测—期望比 | >0.7 |

**基准对比**：随机模型基准（AUC=0.5）与单因子基准（仅 BIO1 年均温）；最优模型 AUC 较单因子基准提升 **≥0.15**。

**样本不平衡处理**：伪缺失点策略合理（距离/环境分层）；类别加权或 SMOTE 后 AUC 稳定（变化 <0.05）。

**地学验证**：与独立出现点/保护区分布重叠率 >60%；误判点是否在栖息地破碎区/人类活动区聚集；未来变迁方向符合物种生态位已知趋势（向高纬/高海拔迁移）。

**LLM 工作流**：Function Calling 成功率 ≥90%；出现点提取坐标越界/异常率 <10%；对话历史可复盘。

# 附录G 期末大作业：城市热岛时空格局与缓解策略分析

> **案例导读**：这是全书最后一项作业，也是唯一一个把**六大自然地理要素**（气候、地貌、植被、水文、土壤、动物）全部卷入的综合案例。城市热岛（UHI）是城市化引起的城区气温显著高于郊区的现象：不透水面替代了植被与土壤，水文过程改变，街谷形态改变通风，鸟类群落随之变化——一座城市就是六大要素耦合的天然实验场。本案例以广州为研究区，完成"UHI 提取 → 时空格局 → 驱动力建模 → 多要素耦合 → 缓解情景模拟 → 政策建议"的全链条分析，并把整个流程交给 MATLAB LLM 综合智能体编排（≥10 个工具函数），最终产出交互仪表板。做完它，你应当有信心独立完成一项完整的综合地学课题。

**综合要素**：气候 + 地貌 + 水文 + 土壤 + 植被 + 动物　|　**难度**：★★★★　|　**建议学时**：20~30 学时（3~4 人一组）
**方法对应**：全书综合——聚类、降维、线性模型、决策树、SVM、深度学习、Transformer、LLM 智能体（[第15章](../ch15.md)）

## G.1 案例背景与研究问题

### G.1.1 地学背景：热岛与六要素的耦合

城市热岛（Urban Heat Island, UHI）与六大自然地理要素深度耦合，这正是选它做期末综合题的原因：

| 要素 | 与 UHI 的耦合 |
|------|---------------|
| 气候 | UHI 本身是局地气候异常，受天气形势、风速、云量调制 |
| 地貌 | 城市地形与建筑高度形成街谷，影响辐射与通风 |
| 植被 | 绿地/水体蒸散降温是缓解 UHI 的关键手段 |
| 水文 | 不透水面增加使地表径流加大、蒸发减少，加剧热岛与内涝 |
| 土壤 | 城市土壤压实、覆盖减少水分下渗与蒸发 |
| 动物 | 热岛改变城市鸟类、昆虫的分布与物候 |

UHI 时空格局分析需融合遥感地表温度 LST、气象站、土地覆被、建筑三维、人口等多源数据，是典型的综合地学问题——**没有哪个单章方法能独立解决它**。

### G.1.2 研究问题

以某大城市为研究对象，分析 UHI 时空格局并提出缓解策略。问题分五层递进：

- **基础问题①（UHI 提取）**：由 Landsat/MODIS LST 反演地表温度，计算 UHI 强度；
- **基础问题②（驱动力分析）**：用线性模型/决策树分析不透水面、NDVI、水体、建筑高度、人口对 UHI 的贡献；
- **基础问题③（时空聚类）**：对 UHI 时序做聚类，识别热岛核心区与昼夜/季节模式；
- **基础问题④（多要素耦合）**：量化植被—水文—土壤对 UHI 的调节作用，关联动物分布变化；
- **综合问题**：构建"UHI 提取 → 驱动力建模 → 时空聚类 → 多要素耦合 → 缓解情景模拟 → 政策建议"的综合智能体工作流，输出交互仪表板。

### G.1.3 地学假设

1. UHI 强度与不透水面比例正相关、与 NDVI/水体比例负相关；
2. 白天与夜间 UHI 机制不同（白天辐射加热 vs 夜间蓄热释放）——**昼夜要分别分析**；
3. 绿地/水体/高反照率材料可显著缓解 UHI，缓解效益可被情景模拟量化。

### G.3.2 UHI 计算方法

- **城乡温差法**：$UHI = LST_{urban} - LST_{rural}$（郊区取未建成区均值）；
- **标准化法**：$LST_z=(LST-\mu)/\sigma$，按阈值分级；
- **昼夜分别计算**——白天/夜间机制不同，混合平均会把两者都抹掉。

## G.4 分阶段任务书

本案例任务量大，按五个阶段推进，每阶段有明确的里程碑。

### 阶段一：数据与问题定义（T1~T3）

- **T1 数据采集**：采集研究区 LST、气象站、土地覆被、建筑三维、NDVI、水体、土壤、人口、动物分布，统一坐标系。*检查点：九类数据的图层清单表与研究区总览图。*
- **T2 政策文本结构化提取（LLM）**：从城市气候公报/规划文本提取热浪事件、绿地规划、政策信息（JSON）。*检查点：`policy.json`。*
- **T3 问题定义**：撰写问题定义（含 UHI 机制与六要素假设）。*检查点：报告初稿第 1 章。*

### 阶段二：UHI 提取与时空格局（T4~T6）

- **T4 LST 反演与 UHI 强度计算**（城乡温差法，昼夜分别计算）。*检查点：UHI 强度图（核心区 1–6 ℃ 量级为合理）。*
- **T5 时空聚类**（PCA + K-means）识别 UHI 核心区与昼夜/季节模式。*检查点：核心区图 + 模式分型图（轮廓系数 >0.4）。*
- **T6 趋势分析**（Sen + MK）UHI 长期变化。*检查点：趋势图与显著像元占比。*

### 阶段三：驱动力与多要素耦合（T7~T9）

- **T7 驱动力建模**：线性模型/决策树/SVM 分析 UHI 驱动力，特征重要性解释。*检查点：驱动力对比表 + 重要性排序图。*
- **T8 多要素耦合量化**：植被（NDVI）、水文（水体/不透水面）、土壤（渗透性）、动物（鸟类多样性）对 UHI 的调节。*检查点：调节系数表（符号要与物理机制一致）。*
- **T9 残差空间分析**（Moran's I）：识别遗漏变量。*检查点：Moran's I 值 + 残差聚集区图 + "遗漏变量假设清单"。*

### 阶段四：情景模拟与政策（T10~T11)

- **T10 缓解情景模拟**：增加绿地/水体/高反照率屋顶，用训练好的模型预测 UHI 降低效益。*检查点：多情景对比表（降温效益 0.3–1.5 ℃ 区间为合理）。*
- **T11 政策/管理建议**：基于情景结果提出分区缓解策略。*检查点：政策建议表（措施、目标分区、预期效益、成本、优先级）。*

### 阶段五：智能体工作流与产品（T12~T14）

- **T12 综合智能体工作流**：编排 ≥10 个 Function，覆盖数据 → 建模 → 模拟 → 可视化。*检查点：完整对话历史 JSON。*
- **T13 交互仪表板**：用 MATLAB App Designer 或导出 Web 仪表板。*检查点：仪表板可运行、可交互。*
- **T14 综合报告**：总结 LLM 调用经验与工作流可复现性。*检查点：报告定稿（提交要求见 G.8）。*

!!! warning "综合题的常见失败模式"
    （1）六要素只做了植被和气候，其余要素"凑数"——评分要求六要素均有数据与分析体现；（2）昼夜混算；（3）情景模拟给出与驱动模型不一致的降温值（如 NDVI+0.1 只降 0.01 ℃ 却声称"显著缓解"）；（4）政策建议与数据脱节。避开这四条，等于避开了一票否决项的主要来源（完整评分细则由教师掌握）。

### G.5.2 工具函数契约（≥10 个，需要你实现的函数）

| 函数 | 输入 | 输出 | 职责说明 |
|------|------|------|----------|
| `load_uhi_data` | city, period | LST + 多要素栅格 | 统一投影 |

### G.6.2 结构化提取与生成模板（两例）

**模板一：UHI 驱动力机制解释（`driver_explain.md` 原版）**

```text
# System Prompt
你是城市气候学专家。给定 UHI 驱动力模型的特征重要性（含不透水面、NDVI、
建筑高度、水体、人口、土壤渗透等），请逐因子解释其对 UHI 的物理机制，并判断
方向（正/负贡献）是否符合城市气候学理论。输出 JSON：
[{"factor":"不透水面","importance":0.32,"direction":"正","mechanism":"...","plausible":true}]
机制须涉及：辐射平衡、热容量、蒸散、通风、人为热。不得编造。

# User Prompt
特征重要性：
- 不透水面 0.32
- NDVI 0.21（负相关）
- 建筑高度 0.18
- 水体 0.14（负相关）
- 人口密度 0.12
- 土壤渗透 0.06（负相关）

请解释。
```

**该模板的调试经验**：不透水面正贡献源于热容量大、蒸散少、人为热高；NDVI 负贡献源于蒸散降温与遮蔽；建筑高度带来街谷蓄热、降低风速（夜间正贡献）；对不符合机制的因子（如某次 NDVI 出现正贡献）标记 `plausible:false`，提示可能为共线性伪相关。

**模板二：缓解策略政策建议生成（`policy_advice.md` 原版）**

```text
# System Prompt
你是城市气候与规划顾问。基于提供的 UHI 驱动力分析结果、多要素调节量化、
情景模拟效益，生成可操作的城市热岛缓解策略政策建议。输出 JSON 数组，每条
建议含：
- measure: 措施名称（如增绿地/冷屋顶/通风廊道/水体恢复）
- target_zone: 目标分区
- expected_benefit: 预期降温效益(℃)
- cobenefit: 协同效益（如内涝缓解、生物多样性提升）
- cost_level: 低/中/高
- priority: 1-5
建议须基于提供的数据，不得编造数值；至少给出 5 条、覆盖不同要素。

# User Prompt
研究区：广州
驱动力：不透水面(0.32)、NDVI(-0.21)、建筑高度(0.18)、水体(-0.14)、人口(0.12)
多要素调节：植被 -0.8℃、水体 -0.6℃、土壤渗透 -0.2℃
情景：增 10% 绿地核心区降 0.7℃；增 5% 水体降 0.4℃；冷屋顶覆盖 30% 降 0.5℃
热岛核心区：天河 CBD、珠江新城

请生成政策建议。
```

**该模板的调试经验**：让 LLM 输出结构化 JSON 便于在仪表板中渲染；强制要求"基于数据、不编造数值"，并在 prompt 中重复数据约束；建议须覆盖六要素（植被、水文、土壤、动物协同效益），体现综合性；生成后用 MATLAB 校核 expected_benefit 与情景模拟值一致；priority 由 LLM 建议但需人工复核（成本效益排序）。

## G.7 结果自检指标

**UHI 提取与时空格局**

| 指标 | 说明 | 目标 |
|------|------|------|
| UHI 强度合理性 | 核心区 vs 郊区温差 | 1–6 ℃ 量级 |
| 聚类轮廓系数 | 时空模式分型 | >0.4 |
| 趋势显著性 | MK 检验 p<0.05 像元占比 | 给出占比 |

**驱动力建模**

| 指标 | 说明 | 目标 |
|------|------|------|
| R² | 回归解释力 | >0.6 |
| AUC/ACC（分类） | 若做热岛分级 | AUC>0.85 |
| 特征重要性合理性 | 与理论方向一致占比 | >80% |

**多要素耦合**：植被/水体/土壤调节系数符号正确；动物多样性在热岛核心区变化方向合理。

**情景模拟**：缓解情景降温效益在合理区间（0.3–1.5 ℃）；多情景对比可量化排序。

**地学验证**：残差 Moran's I 分析（识别遗漏变量）；与气象站实测气温趋势一致；政策建议与城市总体规划不冲突。

**LLM 综合工作流**：编排 Function ≥10 个；Function Calling 成功率 ≥90%；对话历史完整可复盘；仪表板可交互展示 UHI、驱动力、情景、政策；调用经验总结到位。

**综合性与可复现性**：六要素均有数据与分析体现；跨城市可复用（换数据即可运行）；报告结构完整、逻辑清晰。

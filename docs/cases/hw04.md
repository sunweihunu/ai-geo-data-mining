# 附录D 土壤案例：土壤属性遥感反演与数字制图

> **案例导读**：挖一个土壤剖面很贵，靠卫星"看"出土壤属性便宜——这就是土壤遥感反演。本案例以黑龙江三江平原农田为研究区，反演土壤有机碳（SOC）并制成全区域属性图：把光谱反射率、光谱指数、地形因子、气候变量组装成特征库，用多元线性回归/kNN/深度学习三种模型对比反演精度，再用最优模型对全区域格网逐像元预测，最后做残差空间自相关分析判断"还有没有漏掉的环境协变量"。案例遵循数字土壤制图（DSM）经典的 **scorpan 框架**，是全书"回归"主线（[第06章](../ch06.md)、[第07章](../ch07.md)、[第11章](../ch11.md)）在土壤的一次完整落地。

**对应要素**：土壤　|　**难度**：★★★　|　**建议学时**：10~14 学时（2~3 人一组）
**方法对应**：[第06章 线性模型](../ch06.md) · [第07章 k最近邻](../ch07.md) · [第11章 深度学习](../ch11.md)

## D.1 案例背景与研究问题

### D.1.1 地学背景

土壤属性（有机碳 SOC、含水量、质地、pH）的空间分布是农业、生态与碳循环研究的基础数据。地面采样稀疏且昂贵，遥感（光学反射率、热红外、微波后向散射、亮度温度）与地形协变量为土壤属性空间反演提供了多源信息。土壤水分遥感反演是典型的回归问题；数字土壤制图（DSM）遵循 **scorpan 模型框架**——土壤属性 S 由土壤 s、气候 c、生物 o、地形 r、母质 p、时空位置 a、时间 n 七类因子解释。理解"哪些因子控制哪些属性"（SOC 受气候与植被、含水量受降雨与质地）比堆模型更重要。

先说 **SOC 为什么值得反演**：它是陆地最大活跃碳库（土壤碳库）的关键分量，变化直接影响大气 CO₂ 浓度——碳循环模型的必要输入；它是土壤肥力的核心（团聚体稳定、持水保肥、供氮），变量施肥拿它的分布图当底图；其分解还是温室气体排放源。而逐点挖剖面化验贵且慢，覆盖全区要成千上万个点——**遥感反演的本质，就是用易观测的环境变量建立"光谱/环境 → SOC"的统计映射，再外推到无采样区。**

再看"卫星怎么才能看见 SOC"。这条信号链相当弱：SOC 高的土壤腐殖质多、颜色深，把可见光—近红外反射率整体压低（"变暗效应"），这是光谱反演的物理基础；但同一段光谱还混进别的因素——土壤水分升高同样压低反射率（方向与有机质相同，最顽固的混淆项）、粗糙度与残茬改变光照几何、一个 30 m 像元常是裸土与植被的混合谱。**直接光谱信号弱、混淆多，正是本案例引入地形、气候等协变量的原因**：地形经水分再分配控制有机质的分解与堆积，气候控制分解速率，植被控制有机质输入——它们不"看见" SOC，却能解释光谱解释不了的那部分变异。

!!! note "scorpan 框架怎么落到本案例"
    DSM 的经典思路：土壤属性 = 七类因子的函数 $S = f(s, c, o, r, p, a, n)$。逐一对照本案例的特征池：

    | 因子 | 本案例对应 |
    |------|-----------|
    | s 土壤 | 反射率本身（表层土壤的混合光谱信号） |
    | c 气候 | 年降雨、均温、生物温度 |
    | o 生物 | NDVI 及其时序统计量 |
    | r 地形 | DEM、坡度、坡向、TWI、TPI |
    | p 母质 | 岩性/土类图，或由光谱+地形组合代理 |
    | a 时空位置 | 采样点坐标（空间分层划分与残差分析用） |
    | n 时间 | 影像与采样同年的时相对齐约束 |

    报告"问题定义"一节按此表逐项说明七类因子各对应哪些特征。

### D.1.2 研究问题

以某区域为研究区，反演土壤属性并制图。问题分四层递进：

- **基础问题①（回归反演）**：以遥感光谱特征 + 地形 + 气候为输入，用线性回归/kNN/深度学习反演土壤有机碳或含水量；
- **基础问题②（特征工程）**：构建光谱指数、地形派生因子、时序统计量；
- **基础问题③（空间制图）**：训练模型后对全区域格网预测，生成土壤属性图；
- **复合问题**：构建"**多源特征 → 模型对比 → 空间制图 → 残差空间分析**"的 DSM 工作流，并分析土壤属性的环境因子解释。

### D.1.3 地学假设

1. 土壤属性与光谱反射率、地形、植被、气候存在可建模关系；
2. 不同土壤属性的主导因子不同（SOC 受气候植被，含水量受降雨质地）；
3. **模型残差应无强空间自相关**——否则提示还有协变量没进模型（这是本案例最精妙的假设，D.7 的 Moran's I 检验就是验证它）。

三条假设各由一个环节检验：假设 1 由 T3/T4 的相关性与精度检验，假设 2 由 T8 的"环境因子解释"专节检验，假设 3 由 T7 的残差 Moran's I 检验——假设不是装饰，是检查点的"验收标准"。

## D.2 学习目标

## D.3 数据集

### D.3.1 主数据集（推荐研究区：黑龙江三江平原农田 SOC）

| 数据 | 来源 | 分辨率 | 字段 |
|------|------|--------|------|
| 土壤采样 | 全国土壤污染状况详查 / 野外实测 | 点 | SOC(g/kg)、pH、质地、深度 |
| Landsat 8 / Sentinel-2 | USGS / ESA | 10–30 m | 多光谱反射率 |
| DEM | SRTM / ALOS | 12–30 m | 高程 |
| 气候 | WorldClim / ERA5 | 1 km/月 | 降雨、温度 |

**坐标系**：统一投影（如 UTM Zone 51N），栅格重采样至 30 m。**时相对齐**：采样年份与影像年份要接近——用 2020 年的影像反演 2010 年的采样点，关系会被耕作变化污染。

**数据获取**：Sentinel-2 https://scihub.copernicus.eu ；WorldClim https://www.worldclim.org ；ERA5 https://cds.climate.copernicus.eu ；土壤数据可用 ISRIC SoilGrids 公开样本替代教学。

### D.3.2 特征工程要点

- **光谱**：各波段反射率 + 光谱指数（NDVI、裸土指数 BI、颜色指数 CI）；
- **地形**：坡度、坡向、TWI、地形位置指数 TPI；
- **气候**：年降雨、均温、生物温度；
- **时序**：植被指数年内统计量（均值、方差、物候参数）。

**光谱波段与指数各"看"什么。** **可见光（蓝/绿/红）**是叶绿素吸收带与有机质"变暗"效应的主区——铁氧化物强烈吸收蓝光、相对反射红光，土壤偏"红"即铁的信号；**近红外（NIR）**是植被叶片结构的高反射台地；**短波红外（SWIR1 约 1.6 μm、SWIR2 约 2.2 μm）**对着黏土矿物 Al—OH 与层间水 2.2 μm 附近的特征吸收，故对黏土矿物与土壤水分敏感（1.4、1.9 μm 是大气水汽强吸收带，星载多光谱不设波段）。据此逐个理解本案例的三个指数：

- **NDVI** = $(\rho_{NIR}-\rho_{Red})/(\rho_{NIR}+\rho_{Red})$：植被绿度，控制有机质的"输入端"（归还量），并指示覆盖对裸土光谱的稀释；
- **裸土指数 BI**：短波红外与可见光的比值型亮度/裸土指标（示例数据实现为 $(\rho_{SWIR1}+\rho_{Blue})/(\rho_{Green}+\rho_{Red})$）——腐殖质多使土壤变暗、BI 偏低；植被盖度高的像元裸土信息被冠层稀释，BI 也提示"这个像元的光谱可不可信"；
- **颜色指数 CI**：可见光—近红外的差值/比值型"颜色"指标（示例数据实现为 $(\rho_{NIR}-\rho_{Green})/\rho_{Green}$）——土壤偏红（铁氧化物）或植被偏绿都会在 CI 留下信号；铁氧化物常与黏粒胶结，CI 还间接指示母质与风化程度。

!!! tip "指数是波段的'打包'，不是新信息"
    指数是把两三个波段按土壤学先验组合成一个数——信息没有增加，但与目标变量更对齐。特征库里原始波段（让模型自己找组合）与指数（把先验喂给线性模型）都要有；两者高度相关是正常的，T3 的热力图与 VIF 负责挑出冗余。

**地形因子为什么与 SOC 有关。** 一句话：**地形控制水分与物质的再分配，水分再分配控制有机质的分解与堆积**。逐个看：

| 地形因子 | 直观含义 | 与 SOC 的关系 |
|------|------|------|
| 高程（DEM） | 海拔基准 | 控制水热组合（气温随海拔递减），山区还控制土层厚度 |
| 坡度 | 陡缓 | 陡坡侵蚀强、土层薄、有机质难积累；缓坡与坡麓利于堆积 |
| 坡向 | 朝向 | 阳坡光照强、蒸发快、分解快；阴坡冷湿、有机质易保存 |
| TWI | $\ln(a/\tan\beta)$，汇流面积与坡度的组合 | 湿度代理：TWI 高的汇水区冷湿，分解慢、SOC 累积高 |
| TPI | 中心像元与邻域平均高程之差 | 区分山顶/坡中/谷底的位置——决定此处是"源"还是"汇" |

!!! note "SOC 常呈右偏分布：先变换再建模"
    采样 SOC 的直方图多半右偏长尾（少数洼地、腐殖质厚处的高值点拖着尾巴），最小二乘会被这几个高值点"拽"偏，残差也偏离正态。对策：对目标做 $\mathrm{SOC}'=\ln(\mathrm{SOC})$ 或 $\mathrm{SOC}'=\sqrt{\mathrm{SOC}}$ 压回右尾；**预测后反变换回 g/kg，RMSE/RPIQ 在原始单位上报告**（反变换引入轻微有偏，报告说明即可）。

!!! warning "训练/测试划分：按空间分层，不要完全随机"
    地理数据有强空间自相关（[第07章](../ch07.md) 引的 Tobler 第一定律），随机划分时每个测试点周围几乎都站着训练近邻，模型"抄邻居答案"就能拿高分——测出的是插值能力，不是反演能力。正确做法是**空间分块留出**：按经纬度网格（或行政区）切块、整块留出做测试，让测试点周围没有训练近邻。T4 的验证集与 T7 的独立验证都遵循这条原则。

## D.4 分步任务指导（任务书）

### T1 数据采集与统一坐标系

- **做什么**：采集土壤采样点（SOC/含水量/pH）+ Landsat/Sentinel-2 反射率 + DEM + 气候，统一坐标系与时相。
- **检查点**：采样点分布图（叠加研究区边界）+ 图层清单表（含时相）。
- **为什么这样做**：多源数据坐标系、分辨率、时相各不相同，任何一项没统一，"在采样点提值"就会提错像元或错位年份，后面所有步骤带病运行——T1 是全流程最便宜的一次纠错机会。
- **常见错误与排查**：① 投影混算——经纬度当平面坐标用，采样点整体偏移数百米，画"采样点叠加影像"即可查出；② 重采样不对——连续量（反射率/DEM/气候）用双线性或三次卷积、类别量（土地利用）用最近邻，混用会出现"过渡值"；③ 云未掩膜——云像元反射率异常，先掩膜再提值；④ 时相错配——影像与采样年份差太远（见 D.3.1），宁可换影像。

### T2 剖面文本结构化提取（LLM）

- **做什么**：用 LLM 从土壤剖面描述/土种志提取采样点深度、质地、有机质等（JSON）。
- **方法提示**：模板见 D.6.2；"有机质"与"有机碳"换算（SOC≈有机质×0.58）在 prompt 中注明保留原始字段；土种志常无经纬度仅有地名，让 LLM 标注地名后地理编码补全或填 null；提取哪一层（建议表层）要写明。
- **检查点**：`profiles.json` + 字段缺失率统计（<20% 达标）。
- **为什么这样做**：土种志覆盖面广、成本低，但"给人读"的文本人工摘录慢且易错——LLM 做结构化提取、MATLAB 做范围校验，正是[第15章](../ch15.md)"模型读懂文本、数值交给工具"的分工；缺失率 <20% 保证这批档案样本真能进模型。
- **常见错误与排查**：① 层次取错——LLM 把底层值当表层值或把各层平均，Prompt 写明"提取表层"，note 保留原文层次供抽查；② 单位混算——g/kg 与 %、有机质与有机碳，见 D.6.2 的失败模式表；③ 坐标编造——土种志常只有县名，规定地名入 note、lon/lat 填 null，再地理编码补全；④ 换算丢原始值——保留 SOM 原始字段，换算只做一遍并注明因子。

### T3 特征工程

- **做什么**：按 D.3.2 构建光谱指数、地形因子、时序统计量特征库。
- **方法提示**：每类特征出相关系数热力图初筛；对特征做 VIF 检查共线性；特征命名规范化（`band2`、`ndvi_mean`、`twi`），后面 LLM 解释时靠名字对号入座。
- **检查点**：特征矩阵 + 特征—SOC 相关性排序表。

**为什么这样做**。特征数量要与样本量匹配：几百个样本配几十上百个特征，自由参数逼近样本数，回归系数不稳、kNN 的距离被无关特征淹没（[第07章](../ch07.md) 7.5.5），深度网络直接背下训练集。经验上特征控制在样本量的十分之一量级，再用两道筛子收缩：热力图挑出与 SOC 无关及彼此冗余（如 NDVI 与红光波段）的特征；VIF>10 说明该特征基本是别人的重复（[第06章](../ch06.md) 6.3.4 多重共线性），同组留一个。命名规范化是给 LLM 解释"对号入座"——`twi` 写成"特征5"就没法翻译回地学机制。

**常见错误与排查**：① 只加不减——R² 虚高与制图乱纹多半源于过参数化；② 只对目标算相关、不看特征间相关——互相相关 0.95 的两个特征同进模型，系数解释互相打架；③ 忘了归一化——kNN 算距离前先标准化（[第07章](../ch07.md) 7.5.5），否则数量级大的特征主导"远近"；④ 命名中途改动——特征名冻结，后续脚本、提示、报告统一引用。

### T4 模型对比

- **做什么**：多元线性回归、kNN、BP/LSTM 深度学习三种模型，10 折 CV，R²/RMSE 对比（[第06章](../ch06.md)、[第07章](../ch07.md)、[第11章](../ch11.md)）。
- **方法提示**：统一 10 折 `cvpartition`；深度学习从浅网络（1 隐层 10 神经元）起步，逐步加深，记录训练时间——**"深度学习比线性好多少"要连同计算成本一起报告**；验证集用**空间留出**（按空间分块）而非随机留出，见 T7。
- **检查点**：三模型 R²/RMSE/RPIQ 对比表 + 散点图（预测 vs 实测，1:1 线）。

**三种模型各有"性格"，对比表要这样读**。线性回归可解释性最好——系数能翻译成"该特征增一个单位，SOC 变多少"，但只会画"平面"，吃不下光谱—SOC 的非线性，精度垫底是**欠拟合**而非"方法差"；kNN 是懒惰学习（[第07章](../ch07.md)），性能全押在"距离找得对不对"上——小样本邻居稀疏，归一化、特征选择与 k/距离度量（[第07章](../ch07.md) 7.5.1、7.5.2）直接决定成败；深度学习最擅长非线性但**需要更多样本**，几百个样本从浅网络（1 隐层 10 神经元）起步，训深了立刻过拟合。读表三要领：① R²/RMSE/RPIQ 方向一致再下结论，只挑一个好看的是自欺；② 散点图对照 1:1 线看**系统性偏差**——低值高估、高值低估是线性拟合非线性的典型形态，也是"该换非线性模型"的证据；③ "深度学习好多少"连同计算成本读——R² 提升 ≥0.08 才值得用（D.7）。

!!! note "过拟合的信号与对策"
    信号：**训练集好、交叉验证/测试集明显差**——训练 R²=0.95 而 10 折 CV R² 只有 0.6，模型在"背题"。对策按代价从小到大：减特征（回 T3）、缩小网络、加正则（Lasso/Ridge 或 Dropout，[第06章](../ch06.md)、[第11章](../ch11.md)）、早停，最后才是补样本。BP 随机初始化，同结构多训几次取平均，别拿一次"手气"下结论。

**常见错误与排查**：① 各模型用了不同划分或特征矩阵——对比失效，划分与特征写成公共函数统一调用；② 标准化在全量数据上一次做完再进 10 折 CV——训练折信息泄漏进验证折（原理同 D.3.2 的警告），应每折内部拟合；③ kNN 拿原始特征直接算距离——见 T3 要点；④ 表格特征一上来就套 LSTM——LSTM 面向序列输入（[第11章](../ch11.md)），逐点特征矩阵先用 BP，确有时序特征再考虑序列模型。

### T5 空间制图

- **做什么**：最优模型对全区域格网预测，生成土壤属性图。
- **方法提示**：格网特征矩阵 `gridX` 与训练特征列顺序严格一致——列错位是制图错误的头号来源；制图后先看直方图是否合理（SOC 不该出现负值）。
- **检查点**：SOC 属性图（带图例与坐标系标注）+ 值域合理性说明。

**为什么这样做**。制图是把模型对全区域每个像元"逐个考试"，考卷必须与练习册同源同批：**协变量与建模时同源同处理**——同一传感器或同源产品、同一投影、同一重采样方法与分辨率、同一时间窗。任何一项不一致，模型面对的就是另一套特征分布，成图会出现莫名的接缝或条带（典型如两景影像各自重采样后拼接，接缝两侧特征差一点，被模型放大成 SOC 阶跃）。`gridX` 列序与训练特征严格一致（列错位是制图错误的头号来源，机制见 D.3.4）；训练时做过的每个变换（标准化、取对数），制图时必须用**训练时拟合的同一组参数**套用。

**常见错误与排查**：① 列错位——`gridX` 列序与训练不一致，SOC 图出现与地物无关的花纹，逐列比对特征名定位；② 协变量不同源——DEM 一半 SRTM 一半 ALOS、重采样方法不一，成图沿数据边界出现直线接缝；③ 变换不一致——制图忘了做训练时的 zscore/取对数、或用了全图统计量而非训练参数，预测值整体漂移；④ 忘了反变换或未查值域——SOC 不该出现负值，直方图一画便知；⑤ 水体、云、建设用地未掩膜——置 NaN 并在图例说明。

### T6 智能体工作流（Function Calling）

- **做什么**：把 T1~T5 封装为工具函数（契约见 D.5.2），LLM 编排。
- **检查点**：完整对话历史 JSON + LLM 中文总结。
- **为什么这样做**：封装成 D.5.2 的契约函数后，每步能单独测试、单独复盘——出问题时分得清是"LLM 选错工具"还是"函数有 bug"；LLM 只决定"调哪个工具、传什么参数"（[第15章](../ch15.md)：数值交给工具，幻觉少一半）。
- **常见错误与排查**：① 函数报错后把原始报错整段塞回对话——应回填报错摘要与修正建议；② 一次连调多个工具——中间结果丢失、出错无法定位，坚持"每步只调一个工具"的 ReAct 节奏（[第15章](../ch15.md)）；③ 对话历史漏记 Observation——复盘依赖完整的 action/observation 配对（D.6.3）；④ 幻觉调用——多半是参数描述不清："类型 + 中文描述"直接影响调用决策（[第15章](../ch15.md)），按 D.5.2 契约补齐。

### T7 地学验证

- **做什么**：独立验证集（**空间留出**，非随机留出）验证；残差 Moran's I 空间自相关分析；与土壤普查图对比空间格局。
- **方法提示**：随机留出的验证集会被空间自相关"美化"，按空间分块（如按经纬度网格分块）留出才能反映真实外推能力；残差 Moran's I 显著为正 → 有协变量遗漏或模型形式不对，把它写进报告的讨论。
- **检查点**：空间留出验证 R²（较随机留出下降 <0.15 为佳）+ 残差 Moran's I 及显著性 + 与普查图的格局一致性讨论。

**指标怎么读**。空间留出 R² 较随机留出下降 <0.15 为佳：下降越大，模型越依赖"抄空间近邻"、外推能力越弱；几乎不下降反而要警惕，先检查分块是否够大。残差 Moran's I 的直觉：度量"相邻样点的残差是否相近"，取值约 [-1, 1]，显著为正说明相邻点误差同高同低——**残差在空间上仍有结构，即还有没被模型"吃掉"的信息**：或是协变量遗漏（质地、母质），或是模型形式不对（该非线性的用了线性），也可能提示把空间位置本身纳入模型。理想状态是接近 0 且检验不显著——残差成了无结构的"纯噪声"。只报数值不报显著性没有意义：I=0.05 在 320 个样点上就可能显著，用置换检验给 p 值。与普查图对比看高低值区与梯度方向是否一致（定性），重分类到相同等级后算 Kappa（≥0.4 中等一致起步）。

**常见错误与排查**：① 独立验证集被训练点包围——分块间留缓冲带或加大块距；② 残差用训练集回代计算——应用 10 折 CV 折外预测或独立验证集预测，训练残差偏乐观；③ Moran's I 显著就不了了之——按 D.6.1 的规则写成"可能遗漏的协变量"清单并给出证据；④ 普查图口径不同直接比——先重分类对齐等级再算一致率。

### T8 输出与报告

- **做什么**：土壤属性图、模型对比表、残差空间图；撰写报告与农田管理建议。
- **检查点**：报告含"环境因子解释"专节——哪些特征重要、方向是否符合土壤学机制。

"环境因子解释"专节：先报各特征的贡献（线性看标准化系数，非线性可用置换重要性），再把排名翻译回 D.1.1 的 scorpan 机制——是否为已知主导因子、**方向是否符合机制**（NDVI 对 SOC 为正、BI 为负才讲得通）。方向讲不通的特征放进"待讨论"如实给出现象，比硬编机制更能体现地学素养。

## D.5 参考智能体工作流

### D.5.1 工作流总览

```text
MATLAB LLM 智能体（编排者）
  ├─ load_soil(study_area)              加载采样点+遥感+地形
  ├─ extract_profile(text_path)         LLM 从土种志提取剖面属性
  ├─ build_features(reflectance, DEM)   光谱指数+地形因子
  ├─ fit_regress(X, y, models)          线性/kNN/深度学习回归对比
  ├─ predict_grid(model, gridX)         全区域格网预测制图
  └─ residual_morans(y, yhat, coords)   残差空间自相关
```

六个函数与 D.4 的任务一一对应（T1/T2/T3/T4/T5/T7）。分工与[第15章](../ch15.md)的 ReAct 循环一致：LLM 是**编排者**——决定调用顺序、解读 observation；每个函数是**执行者**——真正的计算发生在你实现的 MATLAB 代码里。智能体没有神秘的引擎，就是"思考—调用—观察—再思考"的循环加一份清晰的工具契约。

### D.5.2 工具函数契约（需要你实现的函数）

| 函数 | 输入 | 输出 | 职责说明 |
|------|------|------|----------|
| `load_soil` | study_area | 采样点 + 栅格 | 统一投影重采样 |
| `extract_profile` | 土种志文本 | JSON 剖面属性 | LLM 结构化提取 |
| `build_features` | reflectance, DEM | 特征矩阵 | 光谱指数 + 地形 |
| `fit_regress` | X, y, models | 各模型 R²/RMSE + 最优模型 | 10 折 CV |
| `predict_grid` | model, gridX | 属性栅格 | 全区域预测 |
| `residual_morans` | y, yhat, coords | Moran's I + 显著性 | 残差空间自相关 |

把六个函数放进数据流里看：`load_soil` 是**唯一接触原始数据的函数**——读 `data/*.mat`、统一投影分辨率，输出采样表与栅格栈，其余函数只消费它的产物；`extract_profile` 是**旁路**——补出剖面属性，校验后并入采样表；`build_features` 是**特征车间**——产出训练样本表与 `gridX`；`fit_regress` 是**主车间**——吐各模型指标与最优模型；`predict_grid` 把最优模型推向全区域；`residual_morans` 是**终检**——只读不改。

!!! note "样本表—协变量栈联结：为什么提值由 build_features 统一做"
    建模需要"每个采样点的 SOC + 该点的特征"，制图需要"每个像元的特征"，两件事共用一个函数是刻意设计：**采样点提值与格网提值走同一条代码路径**——同一投影换算、同一重采样结果、同一指数公式、同一列序，从源头杜绝"训练特征与制图特征不同源"（T5 的接缝、条带多半由此而来）。

提值的核心步骤伪代码如下（学生版自行实现，变量名不必一致，流程必须一致）：

```text
% 伪代码：build_features 内部的"采样点提值"
输入：samples（lat, lon, SOC, ...）、栅格栈（每层 ny*nx 向量 + 空间参考）
1) 用空间参考把 (lon, lat) 变换到栅格投影坐标 (x, y)；
2) 每个采样点换算为行列号 [row, col]，取各层在该像元的值 → X_s（n×p）；
3) 将 X_s 与 SOC 按 ID 对齐，拼成训练样本表；
4) 全格网特征由各层向量按列直接拼成 gridX（列序与 X_s 一致）；
返回：样本表（训练用）+ gridX（制图用），列名、列序严格一致。
```

`fit_regress` 只给"用法说明 + 典型参数组合 + 返回结构"，不含参考实现（学生版原则）：**线性**用 `fitlm` 或矩阵左除（[第06章](../ch06.md) 表 6-3）；**kNN** 用 `knnsearch` 找邻居、对邻居 SOC 平均或按距离倒数加权（[第07章](../ch07.md) 7.5.3；k 从 2 起步按 CV 曲线选，先 `normalize`）；**BP** 用 `fitnet`（默认 1 隐层 10 神经元）+ `train`。典型组合：`fit_regress(X, y, ["linear","knn","bp"])` 内部统一 `cvpartition(n,"KFold",10)`，kNN 先标准化、BP 固定 `rng` 并记录训练时间。返回 struct 数组：`model / R2 / RMSE / RPIQ / MBE / trainTime / bestModel`，与 D.7 指标表一一对应。

## D.6 Prompt 模板与示例 Prompt 历史

### D.6.1 智能体系统提示词

按附录A的"工具签名 + ReAct 规则"格式改写，工具清单换为 D.5.2 的 6 个函数，并增加本案例特有规则：

```text
规则（新增）：
- 深度学习与线性模型比较时必须同时报告训练时间（计算成本）；
- 残差 Moran's I 显著时，必须给出"可能遗漏的协变量"假设清单，不得略过。
```

两条规则各针对一个真实痛点。前者：深度学习在几百个样本上常"精度提一点、成本翻几番"，强制报告训练时间（配合 T4/D.7 的 ≥0.08 门槛）是防"无脑上深度学习"的硬约束。后者：残差有空间结构是最值得讨论的结果而非"失败"，强制产出假设清单（如"可能遗漏质地、母质"），报告的讨论一节就有了直接素材。

### D.6.2 结构化提取模板：土种志剖面属性（`extract_profile.md` 原版）

```text
# System Prompt
你是土壤学数据工程师。从《中国土种志》式剖面描述文本中，提取每个剖面点的
属性，输出 JSON 数组。字段：id, lon, lat, soil_type(土类), depth_cm, SOC_gkg,
pH, clay_pct, sand_pct, note。单位严格按字段名；缺失填 null；只输出 JSON，
不得编造。

# User Prompt（少样本）
示例："剖面 HB-12，位于海伦县，黑土，0-20cm 有机质 35.2g/kg，pH6.4，黏粒 32%，砂粒 18%。"
输出：[{"id":"HB-12","lon":126.97,"lat":47.46,"soil_type":"黑土","depth_cm":20,
       "SOC_gkg":35.2,"pH":6.4,"clay_pct":32,"sand_pct":18,"note":""}]

处理：
<<<
{SOIL_TEXT}
>>>
```

**该模板的调试经验**：土种志常无经纬度仅有地名，LLM 标注地名后用 MATLAB 地理编码补全或填 null；"有机质"与"有机碳"需换算（SOC≈有机质×0.58），prompt 中注明保留原始字段；层次描述（0-20、20-40）需明确提取哪层（建议表层）；提取后与遥感时相匹配（采样年份与影像年份接近）。

模板各部分的作用：**System Prompt 的字段表是"合同"**——字段名自带单位（`SOC_gkg`、`clay_pct`），模型按字段名决定单位与格式；"缺失填 null"是防编造的退路；"只输出 JSON"让 MATLAB 的 `jsondecode` 直接接手校验。**少样本示例**一次示范了 id 写法、纯数字数值、note 用途与输出形状——模型模仿一个样例的能力远强于遵守十行规则。

三类典型失败模式与修正方法：

| 失败模式 | 典型表现 | 修正方法 |
|---------|---------|---------|
| 层次命名混乱 | 剖面按发生层/深度（0-20、20-40 或 A/B/C 层）逐层描述，模型取了底层值、或把各层平均当作表层 | Prompt 写明"提取表层（最浅层），depth_cm 记录对应深度"；note 保留原文层次描述；MATLAB 抽查 depth_cm 是否为该剖面最浅层 |
| 单位混算 | 有机质 g/kg 与 % 混写（1 g/kg = 0.1%）；"有机质"与"有机碳"不换算直接互填 | 字段名带单位；少样本示例给换算后的数值与原始字段；MATLAB 按当地表层 SOC 合理范围（如 0~60 g/kg）校验，越界标记人工复核 |
| 剖面坐标缺失 | 土种志常只有县名/地名，模型"顺手"编出经纬度 | Prompt 规定地名入 note、lon/lat 填 null；null 率突然升高说明该段文本没被读对；地理编码补全或按县域中心近似并标记精度等级 |

**有机质与有机碳的换算**：传统假定有机质含碳约 58%，即 $\mathrm{SOC} \approx 0.58 \times \mathrm{SOM}$（倒数 1.724 称 **Van Bemmelen 因子**）。它是经验常数，各土类有出入——所以 T2 要求**保留原始字段**：先原样提取"有机质 35.2 g/kg"，换算时注明所用因子。另注意：模板原版为求简短，把示例的"有机质 35.2"直接写进了 `SOC_gkg`——你自己的模板应补上 SOM 原始字段与换算说明，别照抄这个简化。

## D.7 结果自检指标

**回归性能**

| 指标 | 说明 | 目标 |
|------|------|------|
| R² | 决定系数 | >0.55 合格，>0.70 优秀 |
| RMSE | 均方根误差 | 越小越好（相对标准差） |
| RPIQ | IQ/RMSE（IQ 为四分位距） | >1.5 合格 |
| MBE | 平均偏差误差 | 接近 0 |

**逐个指标怎么读**（$y$ 实测、$\hat y$ 预测）：

- **R²（[第06章](../ch06.md) 6.7.1）**：分母是"直接用均值预报"的误差平方和——R²=0.55 即"比抄均值好 55%"。>0.55 合格、>0.70 优秀是 30 m 多光谱反演 SOC 的通行经验线：光谱信号弱、水分与植被混淆重，实验室光谱的高 R² 到影像尺度打对折属正常；明显低于 0.5 先回 T3 查特征与划分。
- **RMSE**：与 SOC 同单位（g/kg），"相对标准差"的含义是 RMSE 应显著小于样本标准差，否则不比"记住均值"强。
- **RPIQ = IQ/RMSE**（IQ 为四分位距 $Q_3-Q_1$）：把误差放进"数据主体跨度"衡量，>1.5 即 RMSE 小于四分位距的约三分之二。比同样常见的 RPD（标准差/RMSE）更适合右偏的 SOC：RPD 的分母被长尾高值拉大，RPIQ 对极值稳健。
- **MBE = mean$(\hat y - y)$**：正号系统性高估、负号系统性低估（对照 T8 的管理建议）；MBE≈0 但 RMSE 大＝误差无偏但散，MBE 偏离 0 先查单位与反变换。

**基准对比**：均值基准（预测全区均值）与线性模型基准；深度学习较线性 R² 提升 **≥0.08** 方视为有效（否则需说明计算成本）。

基准的逻辑与 R² 同源：**均值基准**就是 R² 分母里"抄均值"的预报，任何模型必须先跑赢它；**线性基准**是"可解释性"的标尺——深度学习提升不到 ≥0.08，就坦率用线性模型，把"深度学习更准"留给真实数据去证明。

**特征选择**：重要特征应包含已知主导因子（SOC→气候+植被；含水量→降雨+质地）；多重共线性 VIF<10。

VIF 的直觉：对第 $j$ 个特征用其余特征回归它得 $R_j^2$，$VIF_j = 1/(1-R_j^2)$——VIF=10 即该特征九成方差能被别人解释，系数是"分不清功劳"的重复计账（[第06章](../ch06.md) 6.3.4）。"重要特征应包含已知主导因子"是把统计结果交地学关：入选特征里没有气候或植被类因子，先怀疑特征工程缺料。

**地学验证**：独立验证集（空间留出，非随机留出）R² 下降 <0.15；残差 Moran's I 显著性检验——理想为不显著（无遗漏协变量）；制图与土壤普查图空间格局一致（定性 + Kappa）。

三个判据各卡一道关：**空间留出 R² 下降 <0.15**——"插值"与"外推"能力的差距，下降过大说明主要在抄空间近邻（D.3.2 的警告）；**残差 Moran's I 不显著**——显著为正即提示遗漏协变量或模型形式不对（读法见 T7）；**与普查图格局一致（定性 + Kappa）**——普查图是几十年积累的"粗真值"，Kappa≥0.4 起步，格局对不上先查制图流程再谈科学问题。

**LLM 工作流**：Function Calling 成功率 ≥90%；剖面提取字段缺失率 <20%；对话历史可复盘。

成功率低通常不是模型"笨"，而是工具签名含糊、参数描述缺"类型 + 中文描述"或 JSON 约束不严（[第15章](../ch15.md)），按 D.5.2 契约逐函数排查；缺失率 <20% 与 T2 同源；"可复盘"指按 D.6.3 格式逐对保存 action/observation，能回答"模型为什么这么调"。

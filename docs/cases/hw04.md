# 附录D 土壤案例：土壤属性遥感反演与数字制图

> **案例导读**：挖一个土壤剖面很贵，靠卫星"看"出土壤属性便宜——这就是土壤遥感反演。本案例以黑龙江三江平原农田为研究区，反演土壤有机碳（SOC）并制成全区域属性图：把光谱反射率、光谱指数、地形因子、气候变量组装成特征库，用多元线性回归/kNN/深度学习三种模型对比反演精度，再用最优模型对全区域格网逐像元预测，最后做残差空间自相关分析判断"还有没有漏掉的环境协变量"。案例遵循数字土壤制图（DSM）经典的 **scorpan 框架**，是全书"回归"主线（[第06章](../ch06.md)、[第07章](../ch07.md)、[第11章](../ch11.md)）在土壤的一次完整落地。

**对应要素**：土壤　|　**难度**：★★★　|　**建议学时**：10~14 学时（2~3 人一组）
**方法对应**：[第06章 线性模型](../ch06.md) · [第07章 k最近邻](../ch07.md) · [第11章 深度学习](../ch11.md)

## D.1 案例背景与研究问题

### D.1.1 地学背景

土壤属性（有机碳 SOC、含水量、质地、pH）的空间分布是农业、生态与碳循环研究的基础数据。地面采样稀疏且昂贵，遥感（光学反射率、热红外、微波后向散射、亮度温度）与地形协变量为土壤属性空间反演提供了多源信息。土壤水分遥感反演是典型的回归问题；数字土壤制图（DSM）遵循 **scorpan 模型框架**——土壤属性 S 由土壤 s、气候 c、生物 o、地形 r、母质 p、时空位置 a、时间 n 七类因子解释。理解"哪些因子控制哪些属性"（SOC 受气候与植被、含水量受降雨与质地）比堆模型更重要。

### D.1.2 研究问题

以某区域为研究区，反演土壤属性并制图。问题分四层递进：

- **基础问题①（回归反演）**：以遥感光谱特征 + 地形 + 气候为输入，用线性回归/kNN/深度学习反演土壤有机碳或含水量；
- **基础问题②（特征工程）**：构建光谱指数、地形派生因子、时序统计量；
- **基础问题③（空间制图）**：训练模型后对全区域格网预测，生成土壤属性图；
- **复合问题**：构建"**多源特征 → 模型对比 → 空间制图 → 残差空间分析**"的 DSM 工作流，并分析土壤属性的环境因子解释。

### D.1.3 地学假设

1. 土壤属性与光谱反射率、地形、植被、气候存在可建模关系；
2. 不同土壤属性的主导因子不同（SOC 受气候植被，含水量受降雨质地）；
3. **模型残差应无强空间自相关**——否则提示还有协变量没进模型（这是本案例最精妙的假设，D.7 的 Moran's I 检验就是验证它）。

## D.2 学习目标

1. 掌握多源遥感 + 地形协变量构建土壤反演特征的方法；
2. 能用 MATLAB 实现线性回归、kNN、深度学习回归并做 10 折交叉验证对比；
3. 能用 LLM 从土壤剖面描述文本提取属性，构建 Function Calling 工作流；
4. 学会数字土壤制图与残差空间自相关（Moran's I）分析。

## D.3 数据集

### D.3.1 主数据集（推荐研究区：黑龙江三江平原农田 SOC）

| 数据 | 来源 | 分辨率 | 字段 |
|------|------|--------|------|
| 土壤采样 | 全国土壤污染状况详查 / 野外实测 | 点 | SOC(g/kg)、pH、质地、深度 |
| Landsat 8 / Sentinel-2 | USGS / ESA | 10–30 m | 多光谱反射率 |
| DEM | SRTM / ALOS | 12–30 m | 高程 |
| 气候 | WorldClim / ERA5 | 1 km/月 | 降雨、温度 |
| 土地利用 | ESA WorldCover | 10 m | 类型 |

**坐标系**：统一投影（如 UTM Zone 51N），栅格重采样至 30 m。**时相对齐**：采样年份与影像年份要接近——用 2020 年的影像反演 2010 年的采样点，关系会被耕作变化污染。

**数据获取**：Sentinel-2 https://scihub.copernicus.eu ；WorldClim https://www.worldclim.org ；ERA5 https://cds.climate.copernicus.eu ；土壤数据可用 ISRIC SoilGrids 公开样本替代教学。

### D.3.2 特征工程要点

- **光谱**：各波段反射率 + 光谱指数（NDVI、裸土指数 BI、颜色指数 CI）；
- **地形**：坡度、坡向、TWI、地形位置指数 TPI；
- **气候**：年降雨、均温、生物温度；
- **时序**：植被指数年内统计量（均值、方差、物候参数）。

### D.3.3 备选研究区（四年轮换）

1. **黄土高原 SOC**——干旱半干旱，质地均一；
2. **南方红壤区含水量**——湿润，微波反演；
3. **内蒙古草原 SOC**——草地碳库；
4. **新疆绿洲土壤盐分**——盐渍化反演（目标改为盐分指数）。

## D.4 分步任务指导（任务书）

### T1 数据采集与统一坐标系

- **做什么**：采集土壤采样点（SOC/含水量/pH）+ Landsat/Sentinel-2 反射率 + DEM + 气候，统一坐标系与时相。
- **检查点**：采样点分布图（叠加研究区边界）+ 图层清单表（含时相）。

### T2 剖面文本结构化提取（LLM）

- **做什么**：用 LLM 从土壤剖面描述/土种志提取采样点深度、质地、有机质等（JSON）。
- **方法提示**：模板见 D.6.2；"有机质"与"有机碳"换算（SOC≈有机质×0.58）在 prompt 中注明保留原始字段；土种志常无经纬度仅有地名，让 LLM 标注地名后地理编码补全或填 null；提取哪一层（建议表层）要写明。
- **检查点**：`profiles.json` + 字段缺失率统计（<20% 达标）。

### T3 特征工程

- **做什么**：按 D.3.2 构建光谱指数、地形因子、时序统计量特征库。
- **方法提示**：每类特征出相关系数热力图初筛；对特征做 VIF 检查共线性；特征命名规范化（`band2`、`ndvi_mean`、`twi`），后面 LLM 解释时靠名字对号入座。
- **检查点**：特征矩阵 + 特征—SOC 相关性排序表。

### T4 模型对比

- **做什么**：多元线性回归、kNN、BP/LSTM 深度学习三种模型，10 折 CV，R²/RMSE 对比（[第06章](../ch06.md)、[第07章](../ch07.md)、[第11章](../ch11.md)）。
- **方法提示**：统一 10 折 `cvpartition`；深度学习从浅网络（1 隐层 10 神经元）起步，逐步加深，记录训练时间——**"深度学习比线性好多少"要连同计算成本一起报告**；验证集用**空间留出**（按空间分块）而非随机留出，见 T7。
- **检查点**：三模型 R²/RMSE/RPIQ 对比表 + 散点图（预测 vs 实测，1:1 线）。

### T5 空间制图

- **做什么**：最优模型对全区域格网预测，生成土壤属性图。
- **方法提示**：格网特征矩阵 `gridX` 与训练特征列顺序严格一致——列错位是制图错误的头号来源；制图后先看直方图是否合理（SOC 不该出现负值）。
- **检查点**：SOC 属性图（带图例与坐标系标注）+ 值域合理性说明。

### T6 智能体工作流（Function Calling）

- **做什么**：把 T1~T5 封装为工具函数（契约见 D.5.2），LLM 编排。
- **检查点**：完整对话历史 JSON + LLM 中文总结。

### T7 地学验证

- **做什么**：独立验证集（**空间留出**，非随机留出）验证；残差 Moran's I 空间自相关分析；与土壤普查图对比空间格局。
- **方法提示**：随机留出的验证集会被空间自相关"美化"，按空间分块（如按经纬度网格分块）留出才能反映真实外推能力；残差 Moran's I 显著为正 → 有协变量遗漏或模型形式不对，把它写进报告的讨论。
- **检查点**：空间留出验证 R²（较随机留出下降 <0.15 为佳）+ 残差 Moran's I 及显著性 + 与普查图的格局一致性讨论。

### T8 输出与报告

- **做什么**：土壤属性图、模型对比表、残差空间图；撰写报告与农田管理建议。
- **检查点**：报告含"环境因子解释"专节——哪些特征重要、方向是否符合土壤学机制。

!!! tip "时间安排建议（12 学时版）"
    T1 占 2 学时、T2 占 1 学时、T3 占 2 学时、T4 占 3 学时、T5 占 1 学时、T6 占 1 学时、T7~T8 占 2 学时。

## D.5 参考智能体工作流

### D.5.1 工作流总览

```text
MATLAB LLM 智能体（编排者）
  ├─ load_soil(study_area)              加载采样点+遥感+地形
  ├─ extract_profile(text_path)         LLM 从土种志提取剖面属性
  ├─ build_features(reflectance, DEM)   光谱指数+地形因子
  ├─ fit_regress(X, y, models)          线性/kNN/深度学习回归对比
  ├─ predict_grid(model, gridX)         全区域格网预测制图
  └─ residual_morans(y, yhat, coords)   残差空间自相关
```

### D.5.2 工具函数契约（需要你实现的函数）

| 函数 | 输入 | 输出 | 职责说明 |
|------|------|------|----------|
| `load_soil` | study_area | 采样点 + 栅格 | 统一投影重采样 |
| `extract_profile` | 土种志文本 | JSON 剖面属性 | LLM 结构化提取 |
| `build_features` | reflectance, DEM | 特征矩阵 | 光谱指数 + 地形 |
| `fit_regress` | X, y, models | 各模型 R²/RMSE + 最优模型 | 10 折 CV |
| `predict_grid` | model, gridX | 属性栅格 | 全区域预测 |
| `residual_morans` | y, yhat, coords | Moran's I + 显著性 | 残差空间自相关 |

### D.6.2 结构化提取模板：土种志剖面属性（`extract_profile.md` 原版）

```text
# System Prompt
你是土壤学数据工程师。从《中国土种志》式剖面描述文本中，提取每个剖面点的
属性，输出 JSON 数组。字段：id, lon, lat, soil_type(土类), depth_cm, SOC_gkg,
pH, clay_pct, sand_pct, note。单位严格按字段名；缺失填 null；只输出 JSON，

       "SOC_gkg":35.2,"pH":6.4,"clay_pct":32,"sand_pct":18,"note":""}]

处理：
<<<
{SOIL_TEXT}
>>>
```

**该模板的调试经验**：土种志常无经纬度仅有地名，LLM 标注地名后用 MATLAB 地理编码补全或填 null；"有机质"与"有机碳"需换算（SOC≈有机质×0.58），prompt 中注明保留原始字段；层次描述（0-20、20-40）需明确提取哪层（建议表层）；提取后与遥感时相匹配（采样年份与影像年份接近）。

## D.7 结果自检指标

**回归性能**

| 指标 | 说明 | 目标 |
|------|------|------|
| R² | 决定系数 | >0.55 合格，>0.70 优秀 |
| RMSE | 均方根误差 | 越小越好（相对标准差） |
| RPIQ | IQ/RMSE（IQ 为四分位距） | >1.5 合格 |
| MBE | 平均偏差误差 | 接近 0 |

**基准对比**：均值基准（预测全区均值）与线性模型基准；深度学习较线性 R² 提升 **≥0.08** 方视为有效（否则需说明计算成本）。

**特征选择**：重要特征应包含已知主导因子（SOC→气候+植被；含水量→降雨+质地）；多重共线性 VIF<10。

**地学验证**：独立验证集（空间留出，非随机留出）R² 下降 <0.15；残差 Moran's I 显著性检验——理想为不显著（无遗漏协变量）；制图与土壤普查图空间格局一致（定性 + Kappa）。

**LLM 工作流**：Function Calling 成功率 ≥90%；剖面提取字段缺失率 <20%；对话历史可复盘。

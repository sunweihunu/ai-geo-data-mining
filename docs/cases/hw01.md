# 附录A 水文案例：流域降雨—径流多尺度预报

> **案例导读**：降雨落到流域上，如何变成出口断面的径流？这是水文学的核心过程，也是中长期水文预报的出发点。本案例以珠江流域北江为研究区，构建**多尺度（旬/月/季）径流量预报模型**：先用相关分析与 Lasso 从大量环流、海温与本地气象因子中筛选预报因子，再做水文年型的聚类分型，然后用线性回归与 BP 神经网络建立预报关系，最后把"分型"与"回归"复合成两阶段预报模型并与持久性基准对比。全流程用 MATLAB LLM 智能体编排：从水文年鉴文本中提取洪峰信息、解释因子物理意义、调度各步函数调用。

**对应要素**：水文　|　**难度**：★★　|　**建议学时**：8~12 学时（2~3 人一组）
**方法对应**：[第04章 聚类分析](../ch04.md) · [第06章 线性模型](../ch06.md) · [第09章 人工神经网络](../ch09.md) · [第21章 地学应用一：水文篇](../ch21.md)

## A.1 案例背景与研究问题

### A.1.1 地学背景

降雨—径流关系是水文学的核心过程。降雨扣除植物截留、下渗、填洼与蒸发等损失后形成净雨，净雨经坡地汇流与河网汇流到达流域出口断面，形成我们观测到的流量过程。[第21章](../ch21.md) 讲过，中长期水文预报（预见期 3 天以上、1 年以内）对防汛抗旱、水资源调度至关重要，但它受大气环流、海温、太阳活动等多因子影响：物理水文模型（新安江模型、SWAT 等）参数率定困难、不确定性大；而遥相关因子（副高强度、ENSO 指数等）与径流之间存在统计可挖的滞后关系——这正是机器学习的用武之地。

### A.1.2 研究问题

以某流域出口断面为研究对象，构建**多尺度径流量预报模型**。问题分三层递进：

- **基础问题①（特征工程）**：从 74 项环流指数、NCEP/NCAR 高度场、NOAA 海温场与本地气象水文资料中筛选预报因子；
- **基础问题②（回归预报）**：用线性模型与 BP 神经网络建立"预报因子 → 径流量"映射（[第06章](../ch06.md)、[第09章](../ch09.md)）；
- **基础问题③（聚类分区）**：对历史水文年型做聚类，识别丰/平/枯水年型，为分型预报做准备（[第04章](../ch04.md)）；
- **复合问题**：把分型与回归结合，构建"**年型识别 + 分型预报**"的两阶段模型，检验其是否比单一模型更准。

### A.1.3 地学假设

建模前先立假设，报告里也要回到假设来讨论结果：

1. 径流量与前 n 期大气环流、海温存在遥相关关系（滞后相关）；
2. 流域产汇流受下垫面（植被、土壤、地形）调制，但中长期尺度上气象强迫占主导；
3. 不同水文年型（丰/平/枯）的预报关系结构不同，分型建模可降低不确定性。

## A.2 学习目标

1. 掌握从中长期水文预报的**物理成因**出发选择预报因子的方法，而不是纯数学地"跑遍历"；
2. 能用 MATLAB 实现线性回归、BP 神经网络、K-means 聚类并进行交叉验证；
3. 能用 MATLAB LLM 工具箱接口完成水文年鉴文本的**结构化提取**与 **Function Calling** 智能体工作流；
4. 学会对预报结果做残差时序分析与地学验证，并与基准模型对比。

## A.3 数据集

### A.3.1 主数据集（推荐研究区：珠江流域北江，控制站石角站）

| 数据 | 来源 | 时间 | 时空分辨率 | 字段 |
|------|------|------|-----------|------|
| 径流量 | 广东省水文局 / 珠江水利委员会·水文年鉴 | 1980–2020 | 月/日 | 流量(m³/s)、水位(m) |
| 降雨/蒸发 | 中国气象数据网 CMA | 1980–2020 | 日/月 | 降雨(mm)、蒸发(mm) |
| 74 项环流指数 | 国家气候中心 NCC | 1951–至今 | 月 | 副高面积/强度、极涡、环流指数等 |
| 100/500 hPa 高度场 | NCEP/NCAR 再分析 | 1948–至今 | 月 | 格点高度(gpm)，2.5°×2.5° |
| 北太平洋海温 SST | NOAA OISST | 1981–至今 | 月 | 格点 SST(℃)，1°×1° |

**坐标系**：水文气象量为站点/流域面值（无空间坐标）；环流与海温为经纬度网格（WGS84）。

**数据获取**：CMA https://data.cma.cn （需注册）；NCEP/NCAR https://psl.noaa.gov/data/gridded/data.ncep.reanalysis.html ；NOAA OISST https://www.ncei.noaa.gov/products/optimum-interpolation-sst ；国家气候中心环流指数 http://cmdp.ncc-cma.net 。

### A.3.2 预处理要点

- **流域面雨量**：用泰森多边形或算术平均由站点雨量推求；
- **网格场因子**：提取关键区（如 Niño3.4 区海温、副高区高度）做区域平均，把"一张场图"变成"一个数"；
- **缺失值**：短缺口线性插补，长缺口用多年同月均值插补；
- **标准化**：Z-score 标准化，务必**在训练集上拟合均值方差、再变换测试集**——把整段序列一起标准化是本案例最常见的错误之一。

### A.3.3 备选研究区（四年轮换）

1. **黄河中游花园口站**——干旱半干旱区，超渗产流，含沙量高；
2. **长江汉口站**——大流域，蓄满产流，受水库调度影响显著；
3. **松花江哈尔滨站**——寒区，含冰凌洪水，可关注开河日期预报；
4. **淮河王家坝站**——平原区，易发洪涝，可关注行蓄洪区调度。

切换研究区时只需替换 `data/` 目录与配置文件，工作流与脚本不变。

### A.3.4 示例数据一键生成（教学快速通道）

开发阶段建议先用示例数据把全流程跑通，再换真实数据。下载 [hw01_gen_demo_data.m](data/hw01_gen_demo_data.m) 放入案例工作目录后运行：


生成的 `data/北江石角站.mat` 含 41 年月尺度序列（1980–2020），变量与物理含义：

| 变量 | 尺寸 | 含义 |
|------|------|------|
| `time` | 481×1 datetime | 月时间轴 |
| `P` | 481×1 | 流域面降雨量(mm)，带年周期 |
| `E` | 481×1 | 蒸发量(mm)，与辐射同相、略滞后 |
| `Q` | 481×1 | 出口断面流量(m³/s)，由当月及前 1~2 月降雨驱动并扣蒸发 |

!!! note "为什么先示例、后真实"
    示例数据的信号结构（降雨驱动径流、蒸发扣减）与真实流域一致，可以让你在**没有数据获取障碍**的情况下先把特征选择、聚类、建模、评估的全链路搭好；之后换真实数据时只替换 `data/` 下的 `.mat`（变量名保持一致），代码零改动。这也是"可复现工作流"训练的一部分。

## A.4 分步任务指导（任务书）

以下 T1~T8 按周布置。每步都给出**方法提示**与**检查点**——检查点是"做完这一步你应当能拿出什么"。

### T1 数据采集与预处理

- **做什么**：获取 1980–2020 年月径流、降雨、蒸发及 74 项环流指数；统一为月尺度；缺失值插补；标准化（注意训练/测试分离）。
- **方法提示**：面雨量用泰森多边形；网格场先取关键区平均再入特征池；用 `fillmissing`、`zscore`（或手写，注意分离）。
- **检查点**：一张"时间—变量"覆盖表（每个变量：起止时间、缺测月数、插补方式），一张原始径流过程线。

### T2 年鉴文本结构化提取（LLM）

- **做什么**：让 LLM 从水文年鉴 PDF/文本中逐年提取最大洪峰流量与发生日期，输出严格 JSON。
- **方法提示**：用 A.6.2 的提取模板，少样本示例能有效约束单位与日期格式；长文本分段提取后合并；提取结果用 MATLAB 做范围校验（流量>0、日期合法）并与月序列交叉核对。
- **检查点**：`peaks.json`（year、station、peak_discharge、peak_date、note），并附一段人工抽查对照记录。

### T3 特征选择

- **做什么**：相关分析初筛 + Lasso 压缩（[第06章](../ch06.md) 正则化），并让 LLM 对入选因子逐一解释物理意义。
- **方法提示**：先算各因子与目标月径流的滞后相关（滞后 0~12 个月），画热力图；再对标准化因子做 `lasso`，沿 λ 路径观察入选顺序；把"统计入选"与"物理合理"两条线放在一起核对——统计上显著但物理上讲不通的因子要给出解释或剔除。
- **检查点**：因子入选表（因子名、滞后阶数、相关系数、Lasso 入选 λ 区间、LLM 物理意义解释）。

### T4 年型聚类

- **做什么**：对年径流深序列做 K-means（或层次聚类），划分丰/平/枯年型（[第04章](../ch04.md)）。
- **方法提示**：k 取 3 但要验证——用轮廓系数 `silhouette` 与肘部法；聚类前对年径流距平序列标准化；对照历史涝旱记载定性核查分型结果。
- **检查点**：年型标签序列（如丰水年 12 年、平水年 18 年、枯水年 11 年）与年型—年份对照图。

### T5 建立预报模型

- **做什么**：① 多元线性回归（月尺度）；② BP 神经网络（季尺度）；③ 两阶段"聚类分型 + 分型回归"复合模型。
- **方法提示**：线性用 `fitlm` 或 `fitrlinear`；BP 用 `fitnet`/`train`（[第09章](../ch09.md)），隐层从 5~10 个神经元起试；复合模型先对预报月做年型判别（就近聚类中心），再调用该年型对应的回归模型；统一用前 75% 年份训练、后 25% 测试。
- **检查点**：三种模型的测试集 NSE/RMSE 对比表与预报—实测过程线图。

### T6 智能体工作流（Function Calling）

- **做什么**：把 T1~T5 的核心步骤封装为工具函数（契约见 A.5.2），用 LLM 按 ReAct 模式编排全流程。
- **方法提示**：系统提示词里显式列出函数签名可大幅降低幻觉调用；LLM 输出的工具调用用 JSON Schema 校验，出错回退重试；每步调用都记入对话历史 JSON。
- **检查点**：一段完整可复盘的对话历史 JSON，以及 LLM 最终的中文总结。

### T7 地学验证

- **做什么**：与持久性基准 $\hat Q(t)=Q(t-12)$ 对比；残差时序与年代际分析；洪峰预报能力评估。
- **方法提示**：NSE 见 A.7；要求复合模型较基准提升 ≥0.15 才算有效；对残差做 Mann-Kendall 趋势检验，|τ| 不显著为佳；分年代统计平均偏差看是否系统漂移。
- **检查点**：基准对比表 + 残差时序图 + 年代际偏差柱状图。

### T8 输出与报告

- **做什么**：预报曲线图、残差图、年型分区图；撰写报告与 LLM 调用经验总结。
- **检查点**：按 A.8 的目录结构打包，报告含"问题定义—方法—结果—地学验证—物理意义解释—政策建议"六部分。

!!! tip "时间安排建议（10 学时版）"
    T1 占 2 学时、T2~T3 占 3 学时、T4~T5 占 3 学时、T6 占 1 学时、T7~T8 占 1 学时。T2 的年鉴提取若暂无年鉴文本，可自拟两段仿真年鉴文字练手，重点掌握模板与 JSON 校验。

## A.5 参考智能体工作流

### A.5.1 工作流总览

```text
            ┌──────────────────────────────────────────────────────┐
            │              MATLAB LLM 智能体（编排者）              │
            └──────────────────────────────────────────────────────┘
   步骤1          步骤2             步骤3            步骤4           步骤5
 load_discharge → select_factors → cluster_year → fit_forecast → plot_residual
   (Function)     (Function)       (Function)     (Function)     (Function)
      │              │                 │               │              │
   读取径流       Lasso/相关        K-means年型    线性/BP/复合    残差时空
   降雨蒸发       筛选因子          丰平枯分区      分型预报        可视化
```

LLM 作为**编排者**，根据用户的自然语言指令决定调用哪个工具、以什么顺序调用，把中间结果回填到对话上下文，形成"思考（Thought）—调用（Action）—观察（Observation）—再思考"的 ReAct 循环（[第15章](../ch15.md)）。

### A.5.2 工具函数契约（需要你实现的函数）

| 函数名 | 输入 | 输出 | 职责说明 |
|--------|------|------|----------|
| `load_discharge(station, year_range)` | 站点、年份区间 | struct（time、Q、P、E、环流指数） | 读取 `data/*.mat` 并完成基础预处理 |
| `extract_yearbook(text_path)` | 年鉴文本路径 | JSON（洪峰流量、日期） | 调 LLM 做结构化提取（模板见 A.6.2） |
| `select_factors(X, y, method)` | 因子矩阵、目标 | 选中的因子索引 + 物理意义说明 | Lasso/相关分析，LLM 解释物理意义 |
| `cluster_year(Q_annual, k)` | 年径流序列、k | 年型标签 | K-means 聚类丰/平/枯 |
| `fit_forecast(X, y, model, split)` | 因子、目标、模型名、切分点 | 预测值 + 模型结构 | 线性/BP/复合分型模型 |
| `plot_residual(y_true, y_pred, time)` | 真值、预测、时间 | 图句柄 | 残差时序与年代际分析 |
| `evaluate(y_true, y_pred)` | 真值、预测 | NSE/RMSE/MAE/基准对比 | 指标计算见 A.7 |

!!! note "实现顺序建议"
    先让每个函数在命令行里"单测通过"（输入示例参数能返回约定结构），再接 LLM 编排。函数间用 struct 传递数据、字段名与上表一致，是"换研究区零改动"的关键。

## A.6 Prompt 模板与示例 Prompt 历史

### A.6.1 智能体系统提示词（System Prompt）

```text
你是面向水文预报的 MATLAB 智能体。你可以调用以下工具完成流域降雨-径流多尺度预报任务。
请按 ReAct 模式工作：先思考(Thought)，再决定调用工具(Action)，观察结果(Observation)，
循环直至完成任务，最后给出最终回答。

可用工具：
1. load_discharge(station, year_range) —— 加载水文气象数据
2. extract_yearbook(text_path) —— 从年鉴文本提取洪峰信息
3. select_factors(X, y, method) —— 特征选择
4. cluster_year(Q_annual, k) —— 年型聚类
5. fit_forecast(X, y, model, split) —— 训练预报模型
6. plot_residual(y_true, y_pred, time) —— 残差可视化
7. evaluate(y_true, y_pred) —— 计算指标对比基准

规则：
- 每一步只能调用一个工具；
- 调用工具时输出严格的 JSON：{"tool":"函数名","args":{...}}；
- 收到 Observation 后再决定下一步；
- 完成后用中文总结预报结果、模型对比、地学解释与建议；
- 不得编造数据，所有数值须来自工具返回。
```

**User Prompt 示例**：

```text
请对北江石角站做月尺度径流预报：用 1980-2010 训练，2011-2020 测试，
比较线性回归、BP 神经网络和"年型聚类+分型回归"三种模型，
并与持久性预报基准对比，最后绘制残差时序图。
```

**调用经验**（来自前期调试，写报告时对照检查自己的版本）：

- 在系统提示中显式列出工具签名，可大幅降低 LLM 幻觉调用；
- 用 JSON Schema 校验 LLM 输出的工具调用，错误则回退重试；
- 对话历史保存为 JSON（可另存等价的 Markdown 表示便于阅读），便于复盘与评分；
- 中文提问 + 英文工具名混用时，提示词中固定工具名为英文，避免解析歧义。

### A.6.2 结构化提取模板：从水文年鉴提取洪峰信息

```text
# System Prompt
你是一名水文数据工程师。任务是从用户提供的水文年鉴文本中，提取每一年该站的
年度最大洪峰流量及发生日期。只输出 JSON 数组，不要任何解释性文字。每个元素
包含字段：
- year: 年份（整数）
- station: 站名
- peak_discharge: 最大洪峰流量（m³/s，浮点）
- peak_date: 发生日期（YYYY-MM-DD）
- note: 备注（若无则空字符串）
若某年信息缺失，该字段填 null。务必基于文本，不得编造。

# User Prompt（少样本示例）
示例输入文本：
"2020年石角站年最大流量出现于6月9日，达18500立方米每秒，超警戒水位2.3米。"

示例输出：
[{"year":2020,"station":"石角","peak_discharge":18500.0,"peak_date":"2020-06-09","note":"超警戒2.3m"}]

现在请处理以下文本：
<<<
{YEARBOOK_TEXT}
>>>
```

**该模板的调试经验**：年鉴单位常混用"立方米每秒 / m³/s / 秒立米"，需在 prompt 中明确统一为 m³/s；日期格式多样（"6月9日""6-9""2020/6/9"），少样本示例可有效约束；对长文本分段提取后再合并，避免上下文超限；提取后用 MATLAB 做范围校验（流量>0、日期合法），并与月径流序列交叉验证。

## A.7 结果自检指标

提交前按此表自查（**评分细则由教师掌握**，本表同时是报告"模型评估"一节需要的指标定义）：

**预报精度**

| 指标 | 公式 | 目标 |
|------|------|------|
| NSE（Nash-Sutcliffe 效率系数） | $1-\dfrac{\sum(Q_o-Q_s)^2}{\sum(Q_o-\bar Q_o)^2}$ | >0.6 合格，>0.8 优秀 |
| RMSE | $\sqrt{\tfrac1n\sum(Q_o-Q_s)^2}$ | 越小越好 |
| MAE | $\tfrac1n\sum\|Q_o-Q_s\|$ | 越小越好 |
| PBIAS | $\dfrac{\sum(Q_s-Q_o)}{\sum Q_o}\times100\%$ | \|PBIAS\|<10% 优秀 |

**基准对比**：持久性基准取 $\hat Q(t)=Q(t-1)$（月尺度用 $Q(t-12)$）；复合模型的 NSE 较基准提升 **≥0.15** 方视为有效。

**聚类质量**：轮廓系数 ≥0.4；丰/平/枯年型与历史涝旱记载吻合（定性核查）。

**地学验证**：残差时序无明显趋势（Mann-Kendall 检验，|τ| 不显著）；分年代统计预报偏差无系统性漂移；年最大洪峰相对误差 <25%。

**LLM 工作流**：Function Calling 调用成功率 ≥90%；对话历史完整可复盘；Prompt 模板换研究区后无需大改。

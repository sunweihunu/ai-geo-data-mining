# 小作业3 线性模型：采用线性判别分析对鸢尾花分类

**对应章节**：第 06 章 线性模型 ｜ **数据集**：MATLAB 自带 `fisheriris`（`meas` 150×4，`species` 150×1）｜ **核心函数**：`fitcdiscr`

## 题目背景

线性判别分析（LDA）是经典的线性分类模型：假设各类样本服从高斯分布且协方差矩阵相同，
通过估计类均值与共享协方差得到线性判别函数。本习题在 Fisher 鸢尾花数据上训练 LDA 模型，
对三个品种做分类，并评估训练集与验证集的正确率。

`meas` 为 150×4 数值矩阵（萼片长、萼片宽、花瓣长、花瓣宽），`species` 为 150×1 品种元胞数组
（setosa / versicolor / virginica），是需要预测的类别（因变量）。

## 需要完成

1. 用 `rng(100)` 固定随机种子；
2. 用 `randperm` 把 150 个样本的顺序随机打乱，然后**前 70%（105 个）做训练集，后 30%（45 个）做验证集**；
3. 用 `fitcdiscr` 在训练集上训练线性判别分析模型，把模型命名为 `mdl`；
4. 预测训练集与验证集的类别，计算总体正确率 `train_acc` 与 `valid_acc`
   （预测类别与真实类别一致的样本数 ÷ 样本总数，用小数表示，如 0.9778）。

注意事项：

- 随机种子必须是 100，打乱方式必须用 `randperm`，否则划分不同、正确率对不上；
- 模型变量命名为 `mdl`；
- 正确率用小数表示。

!!! question "为什么要先打乱再划分？"
    `fisheriris` 的样本是按品种排序存放的（1–50 行 setosa、51–100 行 versicolor、101–150 行
    virginica）。如果像小作业 2 那样直接顺序切分 70/30，验证集将**全部是 virginica**，
    正确率就失去了意义。对比 `carsmall`（样本本身交错）体会数据整理对建模的影响。

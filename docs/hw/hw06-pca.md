# 小作业1 降维：采用 PCA 对鸢尾花数据降维

**对应章节**：第 05 章 降维 ｜ **数据集**：MATLAB 自带 `fisheriris`（`meas` 150×4）｜ **核心函数**：`pca`

## 题目背景

主成分分析（PCA）把高维数据投影到方差最大的少数个正交方向上，实现降维。本习题对 Fisher 鸢尾花
数据的 150×4 测量矩阵 `meas`（四列：萼片长度、萼片宽度、花瓣长度、花瓣宽度，单位 cm）做 PCA：
计算各主成分的方差贡献率与累计贡献率，并把 10 朵新花投影到前两个主成分上。
（`species` 是品种标注，本题只使用 `meas`。）

## 需要完成

1. 对 `meas` 调用 `pca` 进行主成分分析，得到主成分系数 `coeff`、得分 `score` 与方差 `latent`；
2. 计算每个主成分的**方差贡献率**：`ratio1`、`ratio2`、`ratio3`、`ratio4`
   （该主成分的 `latent` 除以 `latent` 之和）；
3. 计算**前两个主成分的累计贡献率** `cum_ratio`（= ratio1 + ratio2）；
4. 把下列 10 朵新花投影到前两个主成分，得到 10×2 矩阵 `newpc`，并把第一朵新花的投影记为
   `newpc1 = newpc(1,:)`。

```
newflower=[5.2 3.4 1.7 0.2
5.3 3.6 1.6 0.5
4.6 3.6 1.1 0.2
4.9 3.3 1.6 0.5
6.7 3.1 4.4 1.3
5.6 3.0 4.6 1.4
5.8 2.6 4.2 0.9
6.3 2.9 5.3 1.9
6.2 3.4 5.5 2.3
5.7 3.0 5.1 1.8 ];
```

注意事项：

- 对 `meas` 直接使用原始测量值，**不做标准化**；
- `pca` 默认对数据中心化，新样本投影需先减去训练数据的均值：
  `newpc = (newflower - mean(meas)) * coeff(:,1:2)`；
- 主成分按方差从大到小排列；所有比值用小数表示。

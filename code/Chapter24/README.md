## 运行环境与方式

Windows 下不直接调用 python（商店占位符），用 uv 拉取依赖运行：

```bash
uv run --no-project --with matplotlib --with numpy python gen_figures.py
# 网络超时可改用缓存：uv run --offline --no-project --with matplotlib --with numpy python gen_figures.py
```

脚本内 `OUT` 为输出目录的绝对路径（指向 `书稿\figs\ch24`），换机器运行前请相应修改。

风格约定：Microsoft YaHei / SimHei 中文字体；配色 C_BLUE=#1f77b4、C_ORANGE=#ff7f0e、C_GREEN=#2ca02c、C_RED=#d62728、C_PURPLE=#9467bd；savefig dpi=150、bbox_inches="tight"；`rng = np.random.default_rng(42)` 固定随机种子；公式一律 mathtext（如 `$40000 \times 20000$`、`$\hat{p}=f(e;w)$`），不用 Unicode 上下标。运行输出零 Warning（脚本自带 warnings 捕获汇总）；新增图函数请追加到 `__main__` 列表末尾（rng 顺序消耗，追加不影响已有图）。

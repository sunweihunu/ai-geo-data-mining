## 运行环境与说明

- 运行命令（Windows 下用 `uv`，项目根目录执行）：
  `uv run --no-project --with matplotlib --with numpy python 脚本/Chapter1/gen_figures.py`
- 脚本输出目录写死为 `书稿/figs/ch01/`（`OUT` 由脚本位置相对推算），直接运行即可复现全部插图；固定随机种子（全局 `default_rng(42)`，fig1_12 内另用种子 7），输出可复现。
- 本章为概念章，全部插图为示意图，**无外部数据文件**，故无 `data/` 子目录；书稿中仅有一段 3 行 MATLAB 调用范式（`fitcsvm`/`predict`，见书稿 1.2.7 节），无独立案例脚本。
- 图 1-2/1-3/1-8 中的表格数值为示意数据（云量/温度/风速/雨量），取自课件第 42、57 页的示例表。

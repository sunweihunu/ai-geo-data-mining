## 运行环境与说明

### MATLAB 脚本（案例）

- 需要 **MATLAB 及 Statistics and Machine Learning Toolbox**（`pca`、`factoran`、`rotatefactors` 均来自该工具箱）。
- 运行前将 MATLAB 当前文件夹切换到本目录，依次运行 `FA_01_PCA.m`、`FA_02_2F.m`、`FA_02_3F.m`、`FA_03_COV.m` 即可（它们通过 `Regions2004` 函数读取数据）。
- 若 .m 文件中文注释乱码：主页 → 预设 → 编辑器，把默认编码改为 **UTF-8**；旧版 MATLAB 需同时把系统区域设置调整为中文。
- 三种求解方式（PCA 法 / 原始数据最大似然 / 协方差矩阵最大似然）的载荷结构一致，个别数值略有差异，属正常现象（因子分析解不唯一，且不同算法的默认收敛设定不同）；书稿图 5-12~5-14 按"主成分法 + varimax 旋转"绘制，数值以自己的运行输出为准。

### Python 脚本（插图）

- 依赖：`numpy`、`matplotlib`（用 `uv` 免安装直接运行）。**在项目根目录**执行：

  ```
  uv run --no-project --with matplotlib --with numpy python 脚本/Chapter5/gen_figures.py
  ```

- 输出目录为 `书稿/figs/ch05/`（相对项目根目录），已随书稿一并提供生成结果。
- 脚本固定随机种子（`default_rng(42)`）保证可复现；如需追加新图，请把新函数**追加到 `__main__` 列表末尾**，避免影响已有图的随机数顺序。

## 数据说明

`Regions2004` 的 8 列依次为：GDP（亿元）、工业增加值（亿元）、全社会固定资产投资额（亿元）、职工平均工资（元）、城镇居民消费性支出（元）、农村居民消费性支出（元）、居民消费价格指数（2003 年=100）、商品零售价格指数（2003 年=100）。数据转录自课件表格截图（原始来源《中国统计年鉴 2005》），个别数值可能与年鉴略有出入，仅用于教学演示。

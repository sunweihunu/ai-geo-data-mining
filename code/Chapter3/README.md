## 运行环境与说明

- **MATLAB 脚本**（`exp03_preprocess_demo.m`）：基础 MATLAB 即可运行，未用到任何工具箱函数（`randperm`、`intersect`、`corrcoef`、`histogram` 均为核心函数；脚本内局部函数需 R2016b 及以上）。脚本开头 `rng(42)` 固定随机种子，每次运行结果一致。
- **练习设定的调整**：课件原题为 S2 在 1~10000 内完全独立随机生成，此时两个 100 站点数据集的期望交集仅约 1 个，后续"按共同站点合并"无从展开。脚本与书稿让 S2 的 100 个编号中 60 个取自 S1、40 个为新编号，保留"范围相同、重新生成、存在差异"的题设，同时保证集成结果规模可观（详见书稿 3.7.1 节说明）。
- **理论参照值**：由 Y = 10T + P 及 T、P 的均匀分布可推出 r(T,Y) ≈ 0.52、r(P,Y) ≈ 0.86（P 的方差份额更大），运行输出的相关系数量级应与之一致，具体数值以实际输出为准。
- **插图脚本**（`gen_figures.py`）：`uv run --no-project --with matplotlib --with numpy python gen_figures.py`（Windows 下注意脚本内 `OUT` 为绝对路径，按需修改）。
- **本章无外部数据文件**：案例数据全部由脚本内生成，`data/` 目录从缺；地图示例（map1.m~map3.m）依赖 shp 边界数据，随原课件分发，未包含在本归档中。
